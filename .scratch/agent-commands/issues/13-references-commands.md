# 会话引用里的命令消息

Type: task
Status: resolved
Blocked by: 06

## What to build

读取工具遇到带命令快照的用户消息时，写成 `/名字 参数`，后面附上“<Agent 名> 命令：<说明>”。这段文字是给 Agent 读的，放在 `internal/refs`。见[规格](../spec.md)的“会话引用”。

## Acceptance criteria

- [x] 引用一个含命令消息的会话，读取结果里有命令名、参数和说明。
- [x] 旧消息的读取结果不变。
- [x] 先例：`references_test.go`。

## 实现说明

- `refs.said`：命令消息按用户写下的样子还原成 `/名字 参数`。读取正文、搜索和摘要节选都用它，所以搜 `/review` 也能搜到。
- 读取时，命令消息的标题行下面加一行“（调用了 <Agent 名> 的命令 /名字：说明）”，没有说明时只写命令名。说明来自消息里的快照。展开后的提示词只有 Agent 自己知道，这里不写。
- 带 `CommandOutput` 的回复，角色写成“<Agent 名> 命令输出”。
- 没有命令字段的旧消息，输出不变（现有的引用测试都没有改动）。

### 没有验证

- 没有用真实的 Agent 读过带命令的引用，只测了工作台的 MCP 工具。

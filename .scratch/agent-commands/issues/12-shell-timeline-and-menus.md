# 时间线显示命令，以及改走控件时打开菜单

Type: task
Status: ready-for-agent
Blocked by: 06, 07

## What to build

见[规格](../spec.md)的“外壳 / 时间线”和用户故事 24–38。

- 带命令快照的用户消息，显示成命令 chip 加参数；悬停 chip 显示快照里的说明。
- 带命令输出标志的回复，用等宽浅色显示，不显示模型名。
- 有“命令已执行”状态的消息，下方显示一行兜底文字。
- 上下文重置标记沿用现有 `Reset` 标记的显示；措辞不对的话改成适用于两种情形。
- 收到 07 的“打开菜单”哨兵错误时，打开模型菜单或权限模式菜单。

## Acceptance criteria

- [ ] MyGO Tester 覆盖：时间线上的 chip 和悬停说明；命令输出的样式；“命令已执行”那一行；不带参数的 `/model` 打开模型菜单。
- [ ] 旧消息（没有命令字段）显示不变。
- [ ] 两种语言的冒烟测试通过。

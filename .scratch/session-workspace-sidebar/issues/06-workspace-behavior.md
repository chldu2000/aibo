# 浏览文件与 Git 改动时保留什么并在何时刷新

Type: grilling
Label: wayfinder:grilling
Status: resolved
Blocked by: 03

## Question

决定目录展开与预览的范围、忽略文件和二进制文件的表现，以及同一路径同时有暂存和未暂存改动时如何选择差异。明确首次打开、外部变更、关闭重开和跨窗口访问的读取时机；用同工作区切会话、切到另一个工作区、文件被删除、目录没有 Git 仓库等情形验收。

例如，同一工作区在两个窗口中打开，用户正在查看一个文件的暂存差异，后台 Agent 又改写了它。哪些数据可以共享或合并刷新？怎样保留用户选中的比较对象和滚动位置？

## Answer

以会话所属工作区为根，默认遵循 Git 忽略规则，不显示 Git 管理目录；目录在展开时读取，文件在选中时才读取预览。二进制文件、超过上限、已删除、无权打开、越界链接各自标明原因。同一路径的暂存项（HEAD 对索引）和未暂存项（索引对工作树）可以分别选中，用路径加变化类别标识选中项。窗口之间共享同一工作区、同一内容的读取结果和进行中的请求，各窗口保留自己的选择。窗口可见时合并变化通知；重新激活或手动刷新时可以发现只改了索引或分支的情况。旧结果不会覆盖新选择；选中的条目消失时给出提示。普通目录、Git 不可用和读取失败分开呈现。缓存期限和尺寸阈值按实测再定。

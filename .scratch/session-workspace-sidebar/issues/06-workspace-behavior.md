# 浏览文件与 Git 改动时保留什么并在何时刷新

Type: grilling
Label: wayfinder:grilling
Status: open
Blocked by: 03

## Question

决定目录展开与预览的范围、忽略文件和二进制文件的表现，以及同一路径同时有暂存和未暂存改动时如何选择差异。明确首次打开、外部变更、关闭重开和跨窗口访问的读取时机；用同工作区切会话、切到另一个工作区、文件被删除、目录没有 Git 仓库等情形验收。

例如，同一工作区在两个窗口中打开，用户正在查看一个文件的暂存差异，后台 Agent 又改写了它。哪些数据可以共享或合并刷新？怎样保留用户选中的比较对象和滚动位置？

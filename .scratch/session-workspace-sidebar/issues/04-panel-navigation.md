# 从详情和徽章打开侧栏后怎样导航与返回

Type: prototype
Label: wayfinder:prototype
Status: resolved

## Question

用低保真原型比较打开详情、点击活动徽章直达一项、从列表查看详情再返回的路径。主窗口与窄独立窗口中，哪些内容与会话并排，何时切换到单项视图？验证收起后回到原草稿、活动到来时输入焦点稳定、切换会话和工作区时已选内容归属正确。由用户评价布局后再定案。

## Answer

没有单独做低保真原型，直接按首期规格的默认导航交付，用户在真实界面上验收后定案。宽窗口里会话和右侧栏并排显示；空间不够时在侧栏内切换列表和单项，并保留返回路径。收起侧栏后回到原草稿，新活动只更新徽章，不抢输入焦点。主窗口和独立窗口各自维护导航和选择。侧栏宽度、是否允许拖宽、窄窗口转场仍可以后续单独调整。

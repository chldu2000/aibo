# 工作台窗口布局

Type: prototype
Status: resolved
Blocked by: 17

## Question

在“工作区与会话列表的管理（含配置项清单）”确定的结构之上，工作台窗口应该怎样布局？要确定：
- 侧栏（工作区和会话列表）、会话视图、输入框、引用卡片之间怎么排布；
- glass 用在哪些位置；
- 设置界面的形态；
- 是否支持多窗口，以及把会话拆到独立窗口。

可以先用 HTML 做粗略原型；关键细节以 MyGO 原生 UI 的能力为准，参考“用 MyGO 验证会话视图的原生渲染”。

## Answer

原型直接用 MyGO 原生 UI 编写，存档在一次性分支 `prototype/window-layout`（`prototype/window-layout/` 目录），不会合并。

**主体结构：三栏布局**
- **左侧：浮动侧栏**。macOS 26 风格，是一块圆角的系统 Liquid Glass 面板（`glass.Glass{Native: true}`），浮在窗口材质之上，四周留 8 的边距。注意不能用 `Fill()` 加 `Margin` 来留边距，要在外层加 padding。
  - 侧栏内容按工作区分组：工作区标题、“＋”新建会话、“目录不存在”标记、会话条目，最下方是“已归档”。
  - 侧栏底部是齿轮（设置，快捷键 ⌘,）和搜索会话。
- **中间：会话区**。不透明的面板，和侧栏之间留一道缝，透出窗口材质。
  - 顶部是一条浮动的 glass 标题栏，显示 Agent 图标、标题、工作区，右侧是两个图标按钮：“在新窗口打开”和“会话详情”。
  - 消息列表在标题栏下方滚动，顶部有 `ScrollEdge` 渐隐。
- **右侧：会话详情**。点击后浮出一块 glass 面板，盖在会话区上方，不占用常驻栏位。内容包括：
  - Agent 和模型、工作区、原生会话；
  - 审批档位切换；
  - “本会话内始终允许”的规则及撤销；
  - 可读的源工作区；
  - 会话操作：压缩、重命名、归档、删除。
- **窗口**：`Transparent: true`，`Vibrancy: VibrancySidebar`，`TitleBarHiddenInset`。

**设置**
- 设置是全局的，所以入口放在侧栏，不放在会话标题栏。
- 以**弹窗**形式打开，面板用 glass，分为通用、Agent、高级三页。

**输入框**（参考 Cursor 的 Agent 窗口和 Codex、Claude 桌面端）
- 外层是一张 glass 卡片，里面是多行输入区，引用草稿以可移除的胶囊形式显示在输入区上方。
- 底部一行都是图标按钮：添加附件、@ 引用其他会话、模型（只显示）、审批档位（点击切换）。最右侧是圆形按钮：空闲时显示“发送 ↑”，运行时显示“停止 ■”。
- 输入框上方是一排**染色 glass 徽标**：
  - 左侧是状态，数量为 0 时隐藏：终端进程数（蓝）、运行中的子 Agent 数（紫）、待审批数（橙）、收到的引用数（绿）。
  - 右侧是快捷指令，即一键常用操作：压缩上下文、引用会话等。

**卡片与横幅**
- 审批卡片用橙色染色 glass，引用卡片用蓝色染色 glass。
- 未登录、只读工作区等提示横幅用橙色染色 glass。

**Agent 标识**
- 用自绘的 SVG 图标：Claude 是橙底星芒，Codex 是深底 `>_`。鼠标悬停时显示全名。
- 这些不是官方 logo。是否改用官方 logo 要看两家的品牌规范，v1 不用。

**拆出独立窗口**
- 低优先级特性，v1 可以做。会话标题栏有“在新窗口打开”按钮，拆出的窗口只显示会话区。

**UI 颜色规范**
- 所有文字和图标的颜色都取自主题（`Text`、`TextMuted`、`AccentText`、`SurfacePressed` 等），不写死颜色值，以便跟随系统的浅色、深色模式。
- 染色 glass 的色调要提供浅色、深色两套透明度（浅色模式下约为深色的 45%），保证上面的主题文字清晰可读。
- 自带颜色的 SVG（例如 Agent 图标）用 `ui.Image` 显示；单色图标用 SF Symbols 或 `ui.Icon`，跟随文字颜色。

**待验证项**（写进规格，在实现时确认）
- 终端进程数和子 Agent 数能否从两家的事件流中**实时**统计；如果做不到，就退回只显示“有 / 无”。
- 系统材质（窗口 vibrancy、原生 Liquid Glass）在浅色、深色模式下文字是否清晰。原型的截图截不到这些材质，需要在真实窗口里检查。
- 其他平台的 glass 呈现效果，留到以后手动验证（v1 只做 macOS）。

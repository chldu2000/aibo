# 工作区与会话列表的管理（含配置项清单）

Type: grilling
Status: resolved

## Question

工作台外壳中关于数据和操作的部分：
- 工作区怎样添加和移除？移除工作区后，它下面的会话怎么处理？
- 会话列表按什么组织（按工作区还是按时间），怎么排序？
- 会话管理提供哪些操作：重命名、删除（删除后引用失效）、归档、搜索？
- 新建会话时，Agent 和工作区怎么选？
- 汇总 v1 的配置项清单。已经出现过的有：数据目录、Agent 可执行文件路径、引用读取的分页预算、闲置断开时长。逐项确定默认值，以及放在设置里的什么位置。

## 已知前提

- 来自“Agent 的发现、版本兼容与登录引导”：设置里要有 Agent 页面，每个 Agent 显示路径、版本、登录状态和认证方式，提供“选择其他可执行文件”和“重新检测”。
- 来自“审批请求的通道与交互”：会话菜单里要能切换审批档位，并能查看和撤销“本会话内始终允许”的规则。

## Answer

- **添加工作区**：在侧栏点“添加工作区”选择文件夹，或者把文件夹拖进窗口。工作区以规范化的绝对路径识别（会解析符号链接），显示名取文件夹名，鼠标悬停时显示完整路径。
- **目录丢失**：工作区目录在磁盘上找不到时，标记为“目录不存在”。它下面的会话仍可浏览、可被引用，但不能再发消息。可以用“重新定位”指向新的路径来恢复。
- **移除工作区**：只是把工作区从侧栏移除，它下面的会话全部转为归档，数据和引用都保留。要彻底删除，需要另外去删会话。
- **会话列表**：
  - 侧栏按工作区分组，每组可以折叠。
  - 组内按最后活跃时间倒序排列。
  - 每个会话显示 Agent 标记、标题和状态标记。状态包括：运行中、待审批、未连接、出错，以及收到的引用数。
- **会话操作**：
  - **重命名**。
  - **删除**：彻底删除，删除前提示“引用将失效”。
  - **归档 / 取消归档**：归档后会话从所在分组隐藏，移到侧栏底部的“已归档”区，但仍然可以被引用、被搜索。
  - **搜索**：匹配标题和消息正文。直接扫描数据库，不建全文索引，最多返回 50 条结果。
  - 会话菜单里还有两项：切换审批档位；查看和撤销“本会话内始终允许”的规则（来自“审批请求的通道与交互”）。
- **新建会话**：在工作区分组标题上点“＋”，选择 Agent。不可用的 Agent 显示为灰色，并注明原因。模型默认使用 Agent 的默认模型，新建时可以改选。v1 不支持在会话进行中切换模型。
- **配置项清单**（设置窗口分三页）：

| 页 | 配置项 | 默认值 |
|---|---|---|
| 通用 | 数据目录 | `~/Library/Application Support/aibo/` |
| 通用 | 新会话的默认审批档位 | 每次询问 |
| 通用 | 有待审批请求时发系统通知 | 开 |
| Agent | 每个 Agent 的可执行文件路径（自动检测，也可手动指定）；只读显示版本、登录状态和认证方式；“重新检测”按钮 | 自动 |
| 高级 | `read_reference` 每页的 token 预算 | 8k |
| 高级 | `read_message` 每页的 token 预算 | 25k |
| 高级 | 分页时单条工具输出的保留长度 | 2k token |
| 高级 | 闲置自动断开的时长 | 30 分钟 |

外观跟随系统的深浅色模式。v1 只有中文界面，不提供语言设置。

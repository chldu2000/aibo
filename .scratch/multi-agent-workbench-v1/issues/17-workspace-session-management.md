# 工作区与会话列表的管理（含配置项清单）

Type: grilling
Status: open

## Question

工作台外壳中关于数据和操作的部分：
- 工作区怎样添加和移除？移除工作区后，它下面的会话怎么处理？
- 会话列表按什么组织（按工作区还是按时间），怎么排序？
- 会话管理提供哪些操作：重命名、删除（删除后引用失效）、归档、搜索？
- 新建会话时，Agent 和工作区怎么选？
- 汇总 v1 的配置项清单。已经出现过的有：数据目录、Agent 可执行文件路径、引用读取的分页预算、闲置断开时长。逐项确定默认值，以及放在设置里的什么位置。

## 已知前提

- 来自“Agent 的发现、版本兼容与登录引导”：设置里要有 Agent 页面，每个 Agent 显示路径、版本、登录状态和认证方式，提供“选择其他可执行文件”和“重新检测”。
- 来自“审批请求的通道与交互”：会话菜单里要能切换审批档位，并能查看和撤销“本会话内始终允许”的规则。

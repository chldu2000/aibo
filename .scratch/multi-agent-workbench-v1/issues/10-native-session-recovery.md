# 续接原生会话与续接失败时的兜底

Type: grilling
Status: open
Blocked by: 05

## Question

应用重启或重新打开一个会话时，aibo 如何续接对应的 Agent 原生会话？原生会话丢失（用户删了 `~/.claude` 下的文件）或不兼容（Agent 升级后格式变了）导致续接失败时，如何发现，又让用户看到什么？候选兜底方案是新开一个原生会话，再把旧会话作为会话引用交给它。注意它与“规范会话模型”中“一个工作台会话一一对应一个 Agent 原生会话”的冲突：兜底后是在同一个 aibo 会话里换一个原生会话（变成一对多），还是另开一个新的 aibo 会话并引用旧会话？

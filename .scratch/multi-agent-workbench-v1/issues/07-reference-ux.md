# 发起和呈现引用的交互

Type: prototype
Status: resolved
Blocked by: 02, 04

## Question

用户如何选定引用范围并把引用交给另一个 Agent（发到新会话还是已有会话）？引用在接收方输入框和会话记录中如何呈现，用户如何查看引用概要？

## Answer

**发起引用支持两条路径，在接收方都用卡片显示。**

- **在源会话里推送**（原型方案 A）：
  - 在源会话点“引用…”进入选择模式：点一条消息设为起点，Shift+点击扩展范围；也可以“选中整轮”或“选中整个会话”。
  - 底部操作栏显示已选范围，可以先预览引用概要，再点“发给…”。
  - 可选的目标有两类：新会话（选 Agent 和工作区），或已有会话。跨工作区的目标会单独标出。
  - 发出后跳到接收方会话，引用以草稿形式放在它的输入框里，发送前可以移除。
- **在接收方拉取**（原型方案 C）：
  - 在接收方的输入框输入 `@` 或点“＋ 引用”，打开选择面板。
  - 第一步搜索并选择源会话，第二步在时间线上点起点和终点（可以选整轮或整个会话）。
  - 右侧实时预览接收方将看到的引用概要；跨工作区时，概要里会附带警告。
- **在接收方显示为卡片**：
  - 输入框和会话记录里的引用都以卡片呈现，卡片上写明来源 Agent、会话标题、范围和条数，可以展开查看引用概要。
  - 接收方 Agent 调用 `read_reference` 时，会话记录里会出现一行“读取了 #a–#b”，点击可以跳回源会话并高亮引用范围。
- **v1 不做分屏拖拽**（原型方案 B）：等以后支持左右两栏同时浏览两个会话，再加拖拽引用。

原型保存在 `prototype/reference-ux` 分支的 `prototype/reference-ux.html`，这个分支只用来存档，不会合并。

## 后续修正

“aibo 记录与 Agent 实际上下文不一致时的处理”确定可以引用给自己，即源会话和接收方是同一个会话。因此两个发起入口都要能选中当前会话：在源会话里点“发给…”时，候选列表里要有“此会话”；在接收方输入 `@` 拉取时，候选会话里也要包含当前会话。

# 07: 引用搜索

**What to build:** 接收方 Agent 可以用 `search_reference` 在交给它的引用里查找内容：默认按关键词，也可以用正则；可以只搜某一个引用，也可以搜全部引用。结果是带片段的命中列表，可以翻页，Agent 再用 `read_message` 去读命中的那条。

规格：[aibo v1 规格](../../multi-agent-workbench-v1/spec.md)（工作台 MCP server · 搜索）。

**Blocked by:** 04（把整个会话推送为引用）

**Status:** resolved

- [x] 默认按关键词匹配，不区分大小写，多个词必须同时出现；`regex=true` 时按正则匹配，正则无效时返回清楚的错误
- [x] 不传 `ref_id` 时搜索交给当前会话的全部引用；传了就只搜这一个
- [x] 只扫描引用范围内的消息，覆盖正文、工具参数、完整工具输出和附件文件名；思考内容只在 `include_thinking=true` 时搜
- [x] 每页最多 20 个命中，每个命中带序号和约 200 字的片段，支持 cursor 翻页
- [x] 主接缝测试覆盖关键词、正则、范围边界、思考内容开关和翻页

## Comments

- 实现说明：
  - 命中以“消息”为单位：一条消息只算一次，片段取第一处匹配的前后，共约 200 字，压成一行。
  - 结果按引用的交付顺序、再按序号排列。cursor 是 `h<命中偏移>`。
  - 搜全部引用时，源会话已被删除的引用直接跳过，不报错；指定 `ref_id` 搜索时，才报“源会话已被删除”。
  - 搜索不算读取，不记读取记录。
  - 概要的“可用工具”一行加上了 `search_reference`。
- 附件文件名、工具参数和完整工具输出还没有可搜的数据。工具调用在任务 02、03 里接入，附件另有任务；到时 `body()` 加上这些字段，搜索就会一并覆盖。

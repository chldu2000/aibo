# 14: 设置弹窗与数据目录

**What to build:** 用户通过侧栏底部的齿轮或 ⌘, 打开全局设置弹窗，里面有“通用”和“高级”两页（“Agent”页见“Agent 的发现、版本与登录”）。用户可以把数据目录改到自己方便找的位置，aibo 会迁移数据，目标在 iCloud Drive、Dropbox 这类同步盘上时给出警告。自定义的数据目录不可用时，显示“重试 / 重新选择位置 / 退出”，绝不悄悄换成一个空库。aibo 同一时间只运行一个实例，再次启动时直接激活已打开的窗口。

规格：[aibo v1 规格](../../multi-agent-workbench-v1/spec.md)（会话模型与存储 · 存储、工作台外壳 UI · 设置）。

**Blocked by:** 01（工作台骨架：用假 Agent 跑通一个会话）

**Status:** ready-for-agent

- [ ] 设置是全局弹窗，面板用 glass；通用页有数据目录、新会话默认审批档位、待审批系统通知；高级页有两个分页预算、单条工具输出保留长度、闲置断开时长
- [ ] “数据目录在哪里”固定保存在默认位置的小配置文件里；项目目录里不写任何文件
- [ ] 更改数据目录前必须先关闭所有会话；新目录为空时复制、校验、再删除旧数据；新目录已有 aibo 数据时直接使用；同步盘给出警告
- [ ] 数据目录不可用时显示三个选项，不新建空库
- [ ] 对数据目录加文件锁；第二个实例启动时激活已有窗口后退出
- [ ] 数据库结构有版本号，升级前先备份数据库文件
- [ ] 主接缝测试覆盖迁移、目录不可用、单实例锁、升级前备份

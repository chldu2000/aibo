# 09: 跨工作区引用

**What to build:** 用户把工作区 A 里的会话引用给工作区 B 里的会话时，界面上会提示这是跨工作区引用。接收方 Agent 可以只读访问源工作区的文件，读取结果开头写明源工作区的绝对路径，并提醒“文件可能已在引用之后被修改”。这份授权在会话的整个生命周期内有效，会话详情里能看到“可读的源工作区”。

规格：[aibo v1 规格](../../multi-agent-workbench-v1/spec.md)（会话运行时 · 跨工作区引用、引用概要规则）。

**Blocked by:** 08（真实 Agent 读取引用）

**Status:** ready-for-agent

- [ ] 概要里只在跨工作区时出现“源工作区”一行；路径不改写
- [ ] 读取工具的输出开头带源工作区路径和“文件可能已修改”的提醒
- [ ] Claude：会话中途收到跨工作区引用时，先用 `--resume` 加 `--add-dir` 重启进程，再发送消息；`--add-dir` 放在提示词之后
- [ ] Codex：不把源工作区加入可写目录
- [ ] 验证 Claude 能否按路径禁止对源工作区 Edit/Write（规格待验证项 2）：能做到就加规则；做不到就在规格里记下结论，由“审批卡片与原生选项”负责标注“写入其他工作区”
- [ ] 额外可读目录记入会话元数据，续接时重新带上
- [ ] 契约测试（环境变量开启）：两家真实 Agent 都能读到源工作区里的文件

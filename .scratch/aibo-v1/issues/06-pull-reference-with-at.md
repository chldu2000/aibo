# 06: 在接收方用 @ 拉取引用

**What to build:** 用户在接收方会话的输入框里输入 `@`（或点输入框底部的 @ 按钮），弹出面板：先搜索并选中源会话，再在它的时间线上选起点和终点，同时实时预览概要，最后插入引用。引用以草稿胶囊出现在输入框里，和推送路径的效果一致。

规格：[aibo v1 规格](../../multi-agent-workbench-v1/spec.md)（用户故事 31–32）。原型：`prototype/reference-ux` 分支。

**Blocked by:** 05（精确引用范围与发往新会话）

**Status:** resolved

- [x] 输入 `@` 或点击 @ 按钮打开面板；可以按标题搜索源会话，包括其他工作区和已归档的会话
- [x] 在源会话时间线上选起点和终点，规整规则与推送路径一致
- [x] 概要随选择实时更新
- [x] 插入后输入框里出现草稿胶囊，发送前可以移除
- [x] 界面测试（MyGO 无窗口 Tester + 核心 + 假 Agent）覆盖“用 @ 拉取引用并发出”

## Comments

- 实现说明：
  - `@` 会输入文字，所以 `OnTextKey` 拦截不到。改为比较输入框前后两次的内容：一次编辑插入的文字以 `@` 结尾时（逐键输入或输入法上屏都算），删掉这个 `@`，打开面板；粘贴 `a@b` 这样的文字不会触发。
  - 面板分两步：先按标题搜索源会话（列出所有工作区，不含当前会话），再在时间线上选范围。选择规则和选择模式一样（补齐空隙、选中整轮、选中整个会话），右侧是实时概要，只在范围变化时重新生成。
  - 面板关闭后（插入、取消或 Esc），光标回到输入框，所以插入后可以直接按 Enter 发送。
- 暂未覆盖：搜索“已归档”的会话。归档要到任务 16 才有，届时把归档会话也列进搜索结果。

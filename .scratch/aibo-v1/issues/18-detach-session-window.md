# 18: 把会话拆出独立窗口

**What to build:** 用户点击会话标题栏上的“在新窗口打开”，这个会话就拆到一个单独的窗口里，方便同时盯着两个会话。拆出的窗口只显示会话区（标题栏、消息列表、输入框），不带侧栏。优先级低。

规格：[aibo v1 规格](../../multi-agent-workbench-v1/spec.md)（工作台外壳 UI · 拆出独立窗口）。

**Blocked by:** 17（Liquid Glass 外壳与输入框）

**Status:** ready-for-agent

- [ ] 点击“在新窗口打开”后，会话出现在新窗口里，只显示会话区
- [ ] 两个窗口里的同一个会话状态一致（流式输出、审批卡片、徽标）
- [ ] 关闭独立窗口不会中断会话；主窗口里仍能打开它
- [ ] 系统通知跳转到审批卡片时，会话已在独立窗口里打开的，激活那个窗口

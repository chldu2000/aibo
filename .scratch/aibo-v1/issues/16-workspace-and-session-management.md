# 16: 工作区与会话管理

**What to build:** 用户可以通过选择文件夹或把文件夹拖进窗口来添加工作区，也可以移除工作区（它下面的会话转为归档，数据保留）。工作区目录被移走或删除时显示“目录不存在”，会话仍可浏览和被引用，并且能“重新定位”到新路径。会话可以重命名、归档和取消归档、按标题和正文搜索、删除（删除前提示“该会话被 N 个引用使用，删除后这些引用将失效”）。侧栏按工作区分组、按最后活跃时间排序，最下方是“已归档”；每个会话条目显示 Agent 图标、标题和状态标记（运行中、待审批、未连接、出错、收到的引用数）。在工作区分组上点“＋”，选好 Agent 和模型后新建会话。

规格：[aibo v1 规格](../../multi-agent-workbench-v1/spec.md)（用户故事 1–13、会话模型与存储 · 删除）。

**Blocked by:** 04（把整个会话推送为引用）

**Status:** ready-for-agent

- [ ] 支持拖入文件夹添加工作区；移除工作区后会话转为归档
- [ ] 目录丢失时显示“目录不存在”，可以重新定位，会话和引用保持有效
- [ ] 重命名后，手动标题优先于默认标题；已发出的引用不受影响
- [ ] 归档的会话从分组隐藏，但可以被引用、被搜索；取消归档后回到原分组
- [ ] 按标题和消息正文搜索会话
- [ ] 删除源会话会彻底删除它，指向它的引用失效；删除接收方会话时，交给它的引用记录一并删除
- [ ] 侧栏状态标记正确反映会话状态；Agent 标识是自绘 SVG，悬停显示全名
- [ ] 新建会话时可以选择 Agent 和模型
- [ ] 主接缝测试覆盖删除会话和移除工作区对引用的影响
- [ ] 界面测试覆盖侧栏状态标记

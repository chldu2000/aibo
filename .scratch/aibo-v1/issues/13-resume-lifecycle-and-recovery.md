# 13: 续接生命周期与续接失败兜底

**What to build:** aibo 启动时不启动任何 Agent 进程，用户在某个会话里发出第一条消息时才续接原生会话；会话闲置 30 分钟后自动断开。原生会话丢失或不兼容、续接失败时，会话顶部出现橙色横幅，附上 Agent 返回的错误原文，提供三个选项：新开原生会话并引用之前的内容（推荐）、新开原生会话但不带引用、暂不处理（会话只读）。选择新开后，会话里出现“已切换到新的 Agent 原生会话”的分隔线。退出 aibo 时如果有会话在运行，先提示用户。

规格：[aibo v1 规格](../../multi-agent-workbench-v1/spec.md)（会话运行时）。

**Blocked by:** 02（在 aibo 里和 Claude Code 对话）、03（在 aibo 里和 Codex 对话）、12（上下文压缩与自引用）

**Status:** ready-for-agent

- [ ] 发首条消息时才续接；闲置 30 分钟断开（Claude 结束进程，Codex 卸载 thread）；有待审批的会话不断开
- [ ] 每次续接都重新生成 MCP token，旧 token 立即作废；同时重新带上额外可读目录和放行规则
- [ ] Claude 的 `--resume` 报错或进程退出、Codex 的 `thread/resume` 返回错误，都判定为续接失败；不预先检查 Agent 的本地存储
- [ ] 三个选项按规格执行；“带引用”时生成一个自引用草稿，范围是重置之前的全部消息
- [ ] 新开原生会话时记录上下文重置标记，原生会话 ID 历史里追加新 ID
- [ ] 退出时，进行中的轮次以“已中断”保存，未处理的审批视为拒绝
- [ ] 主接缝测试覆盖闲置断开、有待审批时不断开、token 轮换、续接失败后的三种选择
- [ ] 界面测试覆盖续接失败横幅

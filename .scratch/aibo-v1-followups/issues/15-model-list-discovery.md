# 15 · 检测就绪后按需读取模型列表

Status: resolved

Windows 启动时会话可能先于可执行文件检测显示。以前每个窗口在首帧就读取并缓存模型列表，过早收到的“没有找到 Agent 的可执行文件”会一直留在窗口里。

模型菜单现在等待检测完成。使用默认模型的新会话首次打开菜单才查询；会话指定或报告了模型时，输入框也会按需查询以显示名称与推理强度选项。工作台按 Agent 共享进行中的请求和结果。路径、版本或可见登录状态发生变化时，下一次需要列表才重新读取。失败后重新打开菜单可以重试。

Windows 双窗口交互测试覆盖检测中零读取、就绪后合并请求、失败后重绘与重试、切换会话和更改可执行文件。全量 Go 测试、vet、staticcheck、改动文件的 gofmt 检查和 Windows x64 打包通过。仓库检查脚本在既有文件的 CRLF 格式检查处停止，未运行 race 检查。本次使用可控的测试 Agent 验证请求次数，未用真实账户手动复测。

# 13 · Windows 图标、通用设置排版和标题栏

Status: resolved

- Windows 上 SF Symbols 缺少系统图形。为工作台使用的 27 个符号提供随主题着色的 SVG 后备图形。
- 通用设置之前将说明和所有 Agent 的选择器放在同一行。现在说明独占一行，每个 Agent 的名称与选择器各占一行。
- 主窗口与独立会话窗口的浮动标题栏使用 MyGO 报告的系统按钮宽度计算右边距。

## 验证

修复前在 Windows 上复现了深浅主题下齿轮像素数为零、默认权限标题高达 93 像素、详情按钮与系统按钮区相交。修复后通过深浅主题图标绘制、双 Agent 中文设置布局、主窗口与独立窗口的标题栏回归测试。重新打包并打开 Windows x64 程序，用临时会话核对了原生窗口截图。

Windows 全量 Go 测试、go vet、staticcheck 和本次变更的 gofmt 检查通过。仓库完整检查脚本在已有文件的 CRLF 换行检查处停止，未执行 race 测试。未在 macOS 真机上验证。

# 08: 输入框里打不出“@”

**What to build:** 用户能在输入框里正常打出“@”（例如写邮箱、装饰器、`@types/node`），同时 `@` 仍然能打开引用面板。

现状：`internal/shell/pull.go` 的 `typedAt` 只要发现新插入的文字以“@”结尾，就把它从草稿里删掉、打开 @ 面板。所以打出来的“@”总被吞掉，只能从别处粘贴。

建议的行为（和常见编辑器一致）：
- 只有在行首或空白之后打出“@”才打开面板；紧跟在字母、数字后面（`a@b`）就当普通字符。
- 打开面板时“@”留在草稿里。在面板里选中一项，就用引用标记替换这个“@”；按 Esc 或点面板外关掉，“@”原样留下。
- 粘贴的文字里带“@”，不打开面板（现在粘贴一段以“@”结尾的文字也会触发）。

**Blocked by:** None (can start immediately)。07（文件引用）会改同一个面板，先做这个

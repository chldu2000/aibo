# 16 · 输入框上方的文件与会话引用面板

Status: resolved

输入 `@` 或点击引用按钮后，文件和会话搜索面板贴在输入框上沿，与输入框等宽。搜索内容较少时面板收缩，结果较多时列表可滚动。选择来源会话后在原处选取消息并预览概要，窄窗口将消息列表与预览上下排列。

点击外部控件可直接操作它。按 Esc 或完成插入后，焦点回到草稿。切换会话会清理原面板，上一轮文件搜索的异步结果也只属于原面板。

Windows 上用 MyGO Tester 验证了主窗口和窄独立窗口的面板角色、位置和外部点击，并检查了渲染截图。文件引用、会话范围、取消和继续输入的交互测试通过。全量 Go 测试、vet、staticcheck 和 Windows x64 打包通过。仓库检查脚本因既有文件的 CRLF 格式停止，未运行 race 检查，未在原生窗口人工点验。

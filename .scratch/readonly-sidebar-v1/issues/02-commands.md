# 从终端徽章查看会话的命令和结果

Status: ready-for-agent
Blocked by: 01

首期交付 · [侧栏规格](../spec.md) · 用户故事 2、5、6、7、8

## 交付场景

从现有终端徽章进入当前会话的命令列表；即使运行数归零，仍可从详情入口找到已结束的命令。

## 验收条件

- [ ] 多个调用可按各自标识选择；显示已知命令、工作目录、状态和输出，未知目录与退出码不从会话目录或失败标记推断。
- [ ] 使用已保存的顶层及可归属的子工具记录。空输出、已截断、审批拒绝、执行失败和缺乏后台状态证据有可区分的表达。
- [ ] 打开已结束或恢复的会话不会重跑命令或启动 shell；切换会话后不会显示前一个会话的迟到结果。
- [ ] 用假 Agent 从工作台发起并发命令、结束或打断后重开；用 Tester 验证徽章直达、归零后从详情查历史。

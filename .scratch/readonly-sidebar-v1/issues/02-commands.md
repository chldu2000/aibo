# 从终端徽章查看会话的命令和结果

Status: resolved
Blocked by: 01

首期交付 · [侧栏规格](../spec.md) · 用户故事 2、5、6、7、8

## 交付场景

从现有终端徽章进入当前会话的命令列表；即使运行数归零，仍可从详情入口找到已结束的命令。

## 验收条件

- [x] 多个调用可按各自标识选择；显示已知命令、工作目录、状态和输出，未知目录与退出码不从会话目录或失败标记推断。
- [x] 使用已保存的顶层及可归属的子工具记录。空输出、已截断、审批拒绝、执行失败和缺乏后台状态证据有可区分的表达。
- [x] 打开已结束或恢复的会话不会重跑命令或启动 shell；切换会话后不会显示前一个会话的迟到结果。
- [x] 用假 Agent 从工作台发起并发命令、结束或打断后重开；用 Tester 验证徽章直达、归零后从详情查历史。

## 依据

[命令与后台任务证据](../../session-workspace-sidebar/research/terminal.md)。前置交付见[从会话详情打开和收起右侧栏](01-panel.md)。

## 实现与验证

运行徽章直达命令详情或多项列表，会话详情保留历史入口。Windows 工作台回归覆盖并发活动、父子归属、输出截断、未完成调用和重新打开数据库后的退出码；MyGO Tester 覆盖运行时进入、归零后查看历史与返回。默认全量测试、vet 和 staticcheck 通过。race 缺少 GCC。

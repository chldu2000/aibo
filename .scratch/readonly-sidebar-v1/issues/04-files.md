# 浏览当前工作区目录并只读预览文件

Status: resolved
Blocked by: 01

首期交付 · [侧栏规格](../spec.md) · 用户故事 11、12、13、14、15

## 交付场景

提供工作区文件树和按需预览。浏览范围取会话自己的工作区，文件提及已有的忽略规则和路径表达可复用。

## 验收条件

- [x] 展开目录才列出其直接子项，选择文件才读取内容；普通非 Git 目录和空目录可浏览，忽略项的默认可见性有明确定义。
- [x] 可读文本能选择和复制。二进制、无权限、已删除、超限条目分别给出原因；目录链接或特殊文件不会引出工作区外内容或阻塞读取。
- [x] 同工作区切会话保留目录与选中项，切到另一工作区显示其目录；独立窗口的选择不会改写主窗口所选文件。
- [x] 用临时目录覆盖空目录、Git 忽略项、特殊名称、读取失败及可构造的越界链接；用 Tester 检查窄窗口预览后返回。

## 依据

[工作区文件与 Git 差异的来源](../../session-workspace-sidebar/research/workspace.md)。前置交付见[从会话详情打开和收起右侧栏](01-panel.md)。

## 实现与验证

工作台用普通目录和真实 Git 仓库验证逐层列举、忽略规则、受限路径、文本截断和二进制文件。MyGO Tester 验证文件选择随工作区保留。Windows 已通过 scripts/check.sh，包含全量 race 测试。

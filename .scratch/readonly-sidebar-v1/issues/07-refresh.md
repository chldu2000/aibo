# 多个窗口按需复用并刷新工作区数据

Status: ready-for-agent
Blocked by: 04, 05, 06

首期交付 · [侧栏规格](../spec.md) · 用户故事 12、21、22、23

## 交付场景

把文件树、文件预览与 Git 列表和差异的首次读取、重开、手动刷新和外部变化统一到工作区范围。

## 验收条件

- [ ] 同一工作区的两个窗口同时请求同一目录或同一差异可合并读取；文件预览选择、差异类别与滚动位置仍属于各自窗口。
- [ ] 合并连续的文件变更通知。纯暂存、分支移动或监听失效后，可通过重新激活可见面板或手动刷新获取最新状态。
- [ ] 面板不可见时停止其自动刷新；其他窗口仍在查看时可继续获取更新。工作区切换或关闭时，旧查询完成不会覆盖当前页面。
- [ ] 通过工作台观察结果、变更通知和实际读取次数，覆盖重复重绘、两个窗口、刷新期间切换工作区、选中项被删除；在 Windows 与 macOS 记录验证结果。

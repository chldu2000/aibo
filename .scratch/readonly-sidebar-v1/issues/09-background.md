# 有存活证据时显示后台终端状态

Status: ready-for-agent
Blocked by: 02

协议增强 · [侧栏规格](../spec.md) · 用户故事 7、8、24

## 交付场景

增强工单。分别验证两家 Agent 提供的后台任务清单或通知，按通过验证的版本启用。

## 验收条件

- [ ] 采样覆盖拒绝执行、工具先返回而后台任务继续、任务终止和重连；对齐调用与任务标识，注明快照覆盖范围。
- [ ] 只将可归属且由新鲜快照或可信事件确认的任务标为后台运行；断线、快照缺失或版本不支持时显示状态未知。
- [ ] 工作台回放验证两个会话中同名命令不会串项，旧快照不覆盖新状态；用真实 CLI 契约验证启用的每种适配器。

[命令与后台任务证据](../../session-workspace-sidebar/research/terminal.md)。前置交付见[从终端徽章查看会话的命令和结果](02-commands.md)。

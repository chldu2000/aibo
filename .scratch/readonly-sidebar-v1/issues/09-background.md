## 交付场景

增强工单。分别验证两家 Agent 提供的后台任务清单或通知，按通过验证的版本启用。

## 验收条件

- [x] 采样覆盖拒绝执行、工具先返回而后台任务继续、任务终止和重连；对齐调用与任务标识，注明快照覆盖范围。
- [x] 只将可归属且由新鲜快照或可信事件确认的任务标为后台运行；断线、快照缺失或版本不支持时显示状态未知。
- [x] 工作台回放验证两个会话中同名命令不会串项，旧快照不覆盖新状态；用真实 CLI 契约验证启用的每种适配器。

## 依据

[命令与后台任务证据](../../session-workspace-sidebar/research/terminal.md)。前置交付见[从终端徽章查看会话的命令和结果](02-commands.md)。

## 实现与验证

仅对实测的 Codex CLI 0.172.0 启用后台清单。真实样本覆盖拒绝审批、父轮已结束而命令继续、命令结束和重连后无法读取；完成事件迟于父轮时仍更新对应记录。按连接、线程和条目匹配新鲜快照。离线回放、工作台隔离测试、Windows 全量及 race 通过，真实契约复测通过（有一次未观察到增量，该次仍取得了命令结果）。按用户授权未使用 Claude 账号采样，其后台状态显示未知。

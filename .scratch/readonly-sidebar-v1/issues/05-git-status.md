# 查看工作区分支与 Git 改动列表

Status: resolved
Blocked by: 01

首期交付 · [侧栏规格](../spec.md) · 用户故事 12、16、17、18

## 交付场景

给当前工作区增加 Git 只读页，展示分支和每组改动，即使文件浏览尚未交付也可以单独使用。

## 验收条件

- [x] 显示分支或分离 HEAD、尚无提交等状态。列表可区分已暂存、未暂存、未跟踪和冲突；同一路径部分暂存时可分别选中两项。
- [x] 识别改名及原路径；含空格、非 ASCII 或通配符的名称保持完整；工作区是仓库子目录时只呈现属于该工作区的改动。
- [x] 分别呈现干净工作树、普通目录、缺少 Git 和仓库读取失败。后台查询在工作台锁外进行，避免后台状态读取写回索引。
- [x] 用临时 Git 仓库从工作台验证各组状态、普通目录和特殊路径；用 Tester 验证页面可打开并在切换会话后显示正确工作区。

## 依据

[工作区文件与 Git 差异的来源](../../session-workspace-sidebar/research/workspace.md)。前置交付见[从会话详情打开和收起右侧栏](01-panel.md)。

## 实现与验证

Windows 临时仓库覆盖未提交、分离 HEAD、干净工作树、冲突、改名、部分暂存、特殊路径和子目录边界。Tester 覆盖打开状态页与切换工作区。scripts/check.sh 全部通过。

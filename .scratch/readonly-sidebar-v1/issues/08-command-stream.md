# 按协议能力显示 Codex 命令的增量输出

Status: ready-for-agent
Blocked by: 02

协议增强 · [侧栏规格](../spec.md) · 用户故事 6、7、24

## 交付场景

增强工单。目标 Codex CLI 能提供可靠的命令增量后，让用户在命令完成前阅读输出。

## 验收条件

- [ ] 从目标 CLI 取得分段输出、并发命令、无输出或中断的脱敏样本，标明版本；核实线程、轮次与条目标识。
- [ ] 增量按正确调用显示，完成事件与已展示内容核对，正文不重复；遵守输出截断上限，切换会话时不会串流。
- [ ] 离线回放和真实 CLI 契约覆盖该能力；缺少增量时继续显示可用的最终结果。证据不足时记录缺口，保持基础功能可用。

[命令与后台任务证据](../../session-workspace-sidebar/research/terminal.md)。前置交付见[从终端徽章查看会话的命令和结果](02-commands.md)。

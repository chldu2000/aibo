# 从会话详情打开和收起右侧栏

Status: ready-for-agent
Blocked by: none

首期交付 · [侧栏规格](../spec.md) · 用户故事 1、3、4

## 交付场景

把现有会话详情接入右侧栏，在主窗口和独立窗口中交付可用的详情页和返回路径。后续每增加一种内容，同一套导航即可承载。

## 验收条件

- [ ] 从会话标题打开当前会话的详情，已有详情内容与操作仍可用；收起后回到原草稿，选中的会话和草稿文字保留。
- [ ] 宽窗口可并排阅读；窄窗口能进入单项、返回列表、关闭面板，标题控件与输入区都可操作。具体宽度取值随原型校准。
- [ ] 各窗口自行打开、收起和选择条目。后台活动更新徽章时不弹出面板、不切换当前条目、不夺走输入焦点。
- [ ] 用 MyGO Tester 在主窗口和窄独立窗口覆盖上述路径，按仓库惯例检查中英文标签；记录 Windows 与 macOS 外观和焦点的实测范围。

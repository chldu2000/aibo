# 从会话详情打开和收起右侧栏

Status: resolved
Blocked by: none

首期交付 · [侧栏规格](../spec.md) · 用户故事 1、3、4

## 交付场景

把现有会话详情接入右侧栏，在主窗口和独立窗口中交付可用的详情页和返回路径。后续每增加一种内容，同一套导航即可承载。

## 验收条件

- [x] 从会话标题打开当前会话的详情，已有详情内容与操作仍可用；收起后回到原草稿，选中的会话和草稿文字保留。
- [x] 宽窗口可并排阅读；窄窗口能进入单项、返回列表、关闭面板，标题控件与输入区都可操作。具体宽度取值随原型校准。
- [x] 各窗口自行打开、收起和选择条目。后台活动更新徽章时不弹出面板、不切换当前条目、不夺走输入焦点。
- [x] 用 MyGO Tester 在主窗口和窄独立窗口覆盖上述路径，按仓库惯例检查中英文标签；记录 Windows 与 macOS 外观和焦点的实测范围。

## 依据

[侧栏导航决策票](../../session-workspace-sidebar/issues/04-panel-navigation.md)。

## 实现与验证

右侧栏与会话并排显示；可用宽度不足时位于草稿上方。保留原详情操作，关闭后光标回到原草稿。Windows 上的 MyGO Tester 覆盖主窗口、440 像素独立窗口、长路径标题及窗口间状态隔离。全量 Go 测试、vet 与 staticcheck 通过。macOS 原生外观和焦点尚未实机点验；本机缺少 GCC，race 未运行。

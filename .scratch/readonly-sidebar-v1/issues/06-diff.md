# 查看所选改动对应的只读差异

Status: resolved
Blocked by: 05

首期交付 · [侧栏规格](../spec.md) · 用户故事 17、19、20、21

## 交付场景

从 Git 页选中变化后才读取对应差异，并保留选择的比较对象。

## 验收条件

- [x] 同一文件有提交版本 A、暂存版本 B、磁盘版本 C 时，暂存项显示 A→B，未暂存项显示 B→C；同工作区切会话后仍显示原比较。
- [x] 未跟踪文本以空内容与当前文件比较；新增、删除、已识别的改名使用正确的新旧路径；无首次提交也可查看已暂存新增。
- [x] 二进制、冲突或仅权限变化能看到已知状态及路径，空文本补丁不会被解释为没有变更；选中项消失时明确告知用户。
- [x] 用真实临时 Git 仓库校验比较两端、特殊路径和改名后再编辑；用 Tester 验证只读差异、切换比较、返回列表。

## 依据

[工作区文件与 Git 差异的来源](../../session-workspace-sidebar/research/workspace.md)。前置交付见[查看工作区分支与 Git 改动列表](05-git-status.md)。

## 实现与验证

Windows 临时仓库直接校验了提交 A、暂存 B、磁盘 C 的比较方向，也覆盖了首次提交前的新增、改名后编辑、删除、未跟踪文本及失效选择。Tester 验证选择随工作区保留并可返回列表。scripts/check.sh 全部通过。

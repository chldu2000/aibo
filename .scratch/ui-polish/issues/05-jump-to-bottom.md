# 05: 回到底部

Status: ready-for-agent

**What to build:** 往上翻阅时，消息区右下角出现“回到底部”按钮；Agent 有新内容时按钮带提示。

现状：用户往上滚后 `ListState.FollowEnd` 关闭，新回复到了没有任何提示，只能手动滚回去。

- [ ] 列表没有贴底时，在输入区上方、消息列右下显示一个圆形玻璃按钮（`arrow.down`）
- [ ] 不贴底期间有新消息或流式内容增长时，按钮加一个圆点（或显示“新消息”）
- [ ] 点击滚到底并恢复 `FollowEnd`
- [ ] 快捷键 ⌘↓ / Ctrl+End 同样回到底部（焦点不在输入框里时）
- [ ] 高亮跳转（`reveal`）之后按钮自然出现
- [ ] Tester：滚上去出现按钮，点击后贴底；贴底时不出现

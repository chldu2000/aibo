# 24: 详情面板里的大输出贴合面板高度

Status: ready-for-agent

**What to build:** 在详情面板打开终端或子 Agent 的单项时，大输出正好填满面板剩下的高度，不会在下面多出一段要滚动的空间。

现状：`inspectorOutputHeight`（`internal/shell/activities.go:38`）按窗口高度减 240 估出输出框的高度，最少 320。面板上方的内容多时（比如子 Agent 的提示词很长），输出框加上上面的内容会超出面板，下面多出一段要滚动。09 的“没有验证”里已经记下这一点。

- [ ] 活动详情页的主体从滚动区改成列布局：上方的内容（标题、命令或提示词、状态）照常排，输出框 `Grow(1)` 占满剩下的高度
- [ ] 提示词很长时，提示词放进限高的滚动区（例如最高 160），保证输出框至少还有 `outputHeight`
- [ ] 子 Agent 页的记录列表跟着改，长记录仍然能滚动
- [ ] 去掉 `inspectorOutputHeight` 的估算（或者只留作下限）
- [ ] Tester：子 Agent 的提示词有 40 行时，面板里不出现外层滚动，输出框底边贴着面板底边

## 来源

09 的“没有验证”。用户 2026-11-28 确认要做。

# 13: 输入区上方的横幅合并

Status: needs-triage

**What to build:** 同时出现多个横幅时，它们不会在输入区上方叠成一大块。

现状：`banners`（`internal/shell/view.go`）依次画失败、恢复失败、登录、工作区目录丢失、已归档、通知、高亮，最多七种可同时出现，每种一块玻璃。再加未开始的审批卡和徽章行，输入区能占去半个窗口。

- [ ] 定优先级：需要用户做决定的（恢复失败、登录、目录丢失）在前并完整显示；说明性的（已归档、高亮、通知、失败）可折叠
- [ ] 超过两个时，只完整显示最高优先的一个，其余折成一行“还有 N 条提示”，点开展开
- [ ] 能关掉的（通知、高亮）保留关闭按钮
- [ ] Tester：构造四种横幅，只占两块高度；点开后全部可见

## 待定

- 已归档和目录丢失是否应移到标题栏（例如标题旁的标记），而不是横幅：需要用户拍板。

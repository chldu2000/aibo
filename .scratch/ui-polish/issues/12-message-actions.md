# 12: 消息的悬停操作

Status: needs-triage

**What to build:** 鼠标悬停在一条消息上时，右上角出现几个小按钮：复制、引用这条；用户消息还可以“放回输入框”。

现状：消息只能选中文字后复制；引用要先点标题栏按钮进入选择模式（`startSelecting`）再勾选。

- [ ] 复制：Agent 回复复制 Markdown 原文，用户消息复制原文，工具调用复制输出
- [ ] 引用这条：直接把这一条作为引用加进当前会话的草稿（等价于选择模式只选一条后确认）
- [ ] 放回输入框：把用户消息的文字、提及和附件放回草稿（不撤销已发出的那条）
- [ ] 选择模式下不显示悬停操作
- [ ] 按钮的 Label 带上序号，保持画面内唯一
- [ ] Tester：悬停出现按钮，复制写入剪贴板，引用这条后草稿出现引用芯片

## 待定

- “编辑并重发”（从某条用户消息分叉或回滚）：涉及原生会话的回退能力，各家不一样，本单不做；要不要单独立项由用户定。
- 是否保留“引用这条”：如果 19 决定去掉一个引用入口，这里可以替代徽章行的“引用会话”。

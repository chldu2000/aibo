# 14: 序号列只在需要时显示

Status: ready-for-agent

**What to build:** 消息左侧的 `#seq` 列平时不显示，悬停在消息上、处于选择模式或有高亮时才显示，把宽度还给正文。

现状：每行固定 44 宽的 `#%d`（`internal/shell/view.go` 的 `messages`），`working` 和 `divider` 也按 44/58 对齐。窄窗口里很占地方。

- [ ] 平时不占宽度；悬停时在消息左上角浮出序号（不推动布局）
- [ ] 选择模式和有高亮时照常显示序号列，方便对照引用的范围
- [ ] `working`、`divider`、命令标记的缩进随之调整
- [ ] Tester：选择模式下序号可见；Tester 依赖序号文字查找元素的地方改用别的 Label

## 决定（2026-11-27）

- 平时隐藏，悬停浮出。只有引用时才需要对照序号，而引用时会进入选择模式或出现高亮。

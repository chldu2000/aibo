# 16: 新会话的总入口

Status: resolved

**What to build:** 侧栏顶部有一个显眼的“新会话”按钮，⌘N / Ctrl+N 用当前会话的工作区和 Agent 直接新建；需要换时再选。

现状：只能点每个工作区标题上的 +（`newSessionButton`），弹出 Agent 列表；没有快捷键，工作区一多就要先找到对的那组。

- [x] 侧栏头部搜索框上方（或 aibo 字样旁）加“新会话”按钮
- [x] 单击：用当前会话的工作区和 Agent 新建，没有当前会话时用最近活跃的；都没有时打开选择
- [x] 按钮旁的下拉（或右键）：选工作区和 Agent，复用 `newSessionButton` 的弹层内容
- [x] ⌘N / Ctrl+N 同单击；⇧⌘N / Ctrl+Shift+N 打开选择
- [x] Agent 不可用时不直接新建，打开选择并说明原因（沿用 `agentOK`）
- [x] 新建后焦点在输入框
- [x] Tester：快捷键新建的会话属于当前工作区和 Agent；不可用时弹出选择

## 不做

- 工作区标题上的 + 保留不动。

## 实现说明

- **入口**：新文件 `internal/shell/newsession.go`。侧栏头部，在“aibo”那一行和搜索框之间加了一行：
  - 一个占满宽度的“新建会话”按钮，标签“新会话（⌘N）”；
  - 旁边一个下拉箭头按钮，“选择工作区和 Agent 新建（⇧⌘N）”。
  - 按钮上的字没用“新会话”，因为新会话的默认标题就是“新会话”，会和测试里按标题查找会话冲突。
- **单击 / ⌘N**（`startLikeThis`）：
  - 用当前会话的工作区和 Agent 新建；没有当前会话时，用最近活跃的未归档会话。
  - 以下几种情况改为打开选择：一个会话都没有、工作区目录不存在、Agent 不可用（`agentOK`）。Agent 不可用时，选择框顶部会说明原因。
- **选择**：画成对话框（`starterDialog`），没用跟着按钮弹出的小窗，这样侧栏隐藏时按 ⇧⌘N 也能用。
  - 每个工作区一节，下面列 Agent，标签是“在 X 用 Y 新建”，保证同屏不重复。
  - 不可用的 Agent 置灰，并写出原因。
  - 没有工作区时提示添加。
- **复用**：Agent 列表抽成了 `agentChoices`，工作区标题上的 + 弹层和这个对话框共用。
- **快捷键**：⌘N / Ctrl+N 和 ⇧⌘N / Ctrl+Shift+N，用 `ui.Cmd`。会话的独立窗口里不响应。
- **焦点**：`newSession` 新建后把焦点交给新会话的输入框。
- **测试**：
  - `TestNewSessionShortcut`：⌘N 新建的会话属于当前会话的工作区和 Agent（两个工作区、两个 Agent），焦点在新会话的输入框；⇧⌘N 列出每个工作区的每个 Agent，选一个能新建，选完对话框关闭；下拉按钮也能打开选择。
  - `TestNewSessionUnusable`：Agent 不可用时 ⌘N 不新建，而是打开选择并说明原因。

## 没有验证

- 侧栏头部多了一行，搜索框往下挪了大约 34，没有在真机上看过整体效果。
- 按钮的提示写的是 ⌘N。Windows 上实际是 Ctrl+N，和别处的提示一样，留给 18 统一处理。

## 改版：选择改成左右两栏（2026-11-28）

- **起因**：用户试用后提出，工作区和 Agent 多时，原来“每个工作区一节、下面列出全部 Agent”的列表会很长。
- **布局**：对话框加宽到 560，分成两栏。
  - 左栏是工作区：上面有筛选框（按名字或路径，打开时自动聚焦），下面是列表，标签是“选择工作区 X”，避免和侧栏的工作区名字重名。
  - 右栏是选中工作区的名字和路径，以及它的 Agent（沿用 `agentChoices`，不可用的置灰并写出原因），点一个就新建。
- **默认选中**：当前会话所在的工作区（`openStarter`）；没有就选第一个。筛选后原来选中的不在列表里了，就改选剩下的第一个。
- 删掉不再使用的 `newSessionWithIn`，新增 `filterWorkspaces`、`noWorkspaceMatches`、`pickWorkspace`。
- `TestNewSessionShortcut` 改为检查：默认选中当前会话的工作区，右栏列出 Agent；筛选能缩小列表；先选工作区再选 Agent，新会话属于所选的工作区和 Agent。

### 没有验证

- 左栏只能用鼠标选，上下键在列表里移动、回车新建都还没做。
- 两栏的高度固定为 320，工作区很少时下面会空出一块。

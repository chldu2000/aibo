# 16: 新会话的总入口

Status: ready-for-agent

**What to build:** 侧栏顶部有一个显眼的“新会话”按钮，⌘N / Ctrl+N 用当前会话的工作区和 Agent 直接新建；需要换时再选。

现状：只能点每个工作区标题上的 +（`newSessionButton`），弹出 Agent 列表；没有快捷键，工作区一多就要先找到对的那组。

- [ ] 侧栏头部搜索框上方（或 aibo 字样旁）加“新会话”按钮
- [ ] 单击：用当前会话的工作区和 Agent 新建，没有当前会话时用最近活跃的；都没有时打开选择
- [ ] 按钮旁的下拉（或右键）：选工作区和 Agent，复用 `newSessionButton` 的弹层内容
- [ ] ⌘N / Ctrl+N 同单击；⇧⌘N / Ctrl+Shift+N 打开选择
- [ ] Agent 不可用时不直接新建，打开选择并说明原因（沿用 `agentOK`）
- [ ] 新建后焦点在输入框
- [ ] Tester：快捷键新建的会话属于当前工作区和 Agent；不可用时弹出选择

## 不做

- 工作区标题上的 + 保留不动。

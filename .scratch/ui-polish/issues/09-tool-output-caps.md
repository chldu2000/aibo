# 09: 展开的工具调用限高

Status: ready-for-agent

**What to build:** 展开一个工具调用不会把会话撑得很长：参数和小输出都有最大高度，大输出可以挪到详情面板看。

现状（`internal/shell/render.go`）：
- 展开后参数以完整 JSON 显示，不限高。
- 输出不到 4KB（`bigOutput`）时整段作文本显示，可能上百行；超过时用只读编辑器，高度固定 320，不能调。

- [ ] 参数：先显示 `gist` 一行，“显示参数”再展开完整 JSON；JSON 区域最大约 160，超出滚动
- [ ] 小输出：最大约 240，超出在区域内滚动，或者折成前若干行加“显示全部”（二选一，实现时用 MyGO 的 Scroll 更简单）
- [ ] 大输出：编辑器保持 320，旁边加“在详情面板打开”，在详情面板里占满高度
- [ ] 子 Agent 的嵌套调用同样适用
- [ ] Tester：100 行输出展开后高度不超过上限；“在详情面板打开”打开对应项

## 待定

- “在详情面板打开”对非终端、非子 Agent 的调用（Read、Grep 等）该落在哪一页：目前详情面板只有终端和子 Agent 两类活动页。可以新增一个通用的“调用”单项页，或者暂时只给终端和子 Agent 提供。

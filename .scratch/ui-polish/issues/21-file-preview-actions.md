# 21: 文件预览的操作

Status: ready-for-agent

**What to build:** 在详情面板看文件或差异时，能复制路径、在系统里打开或显示，能把它提及到草稿里。

现状：文件页和 Git 差异页只有返回按钮和面包屑（`inspector`），面包屑的路径不能操作。

- [ ] 面包屑右侧加按钮：复制相对路径、在 Finder/资源管理器中显示（`Options.ShowInFinder`）、用默认程序打开（`Options.OpenFile`）
- [ ] “提及到输入框”：把文件作为 @ 提及加进当前会话的草稿（复用 `mention.go` 的提及）
- [ ] 文件树的行右键菜单提供同样的操作
- [ ] 目录丢失或文件已删除时这些按钮禁用
- [ ] Tester：复制路径写入剪贴板；提及后草稿出现芯片

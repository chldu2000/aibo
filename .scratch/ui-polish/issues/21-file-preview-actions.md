# 21: 文件预览的操作

Status: resolved

**What to build:** 在详情面板看文件或差异时，能复制路径、在系统里打开或显示，能把它提及到草稿里。

现状：文件页和 Git 差异页只有返回按钮和面包屑（`inspector`），面包屑的路径不能操作。

- [x] 面包屑右侧加按钮：复制相对路径、在 Finder/资源管理器中显示（`Options.ShowInFinder`）、用默认程序打开（`Options.OpenFile`）
- [x] “提及到输入框”：把文件作为 @ 提及加进当前会话的草稿（复用 `mention.go` 的提及）
- [x] 文件树的行右键菜单提供同样的操作
- [x] 目录丢失或文件已删除时这些按钮禁用
- [x] Tester：复制路径写入剪贴板；提及后草稿出现芯片

## 实现说明

- 新文件 `internal/shell/path_actions.go`。
- **面包屑旁的按钮**：在文件页打开一个文件，或在 Git 页打开一处改动时，面包屑右侧出现四个图标按钮（`pathActions`），依次是：
  - 复制相对路径
  - 在 Finder / 资源管理器中显示：只有应用提供了 `ShowInFinder` 时才有
  - 用默认程序打开：只有应用提供了 `OpenFile` 时才有
  - 提及到输入框
- **提及**：把文件作为提及加进当前会话的草稿，沿用 `mention`，并把焦点交给输入框。
- **右键菜单**：文件树的行（文件和目录都有）提供同样四项（`pathMenu`）。目录提及时带 `Dir`。
- **禁用**：工作区目录丢失，或者文件已删除时，显示、打开、提及三项禁用，复制路径仍可用。
  - 文件页：以预览读取失败判断已删除。
  - Git 页：以状态码含 D 判断已删除。
- **按平台显示名称**：原来写死“在 Finder 中显示”。现在由 `showInLabel` 按平台选，非 macOS 上显示“在资源管理器中显示”，概览里工作区旁的按钮也一起改了。
- 新增 `arrow.up.forward.app` 图标的后备图形。
- 测试 `TestPathActions`：
  - 文件树行的右键菜单能复制路径；
  - 面包屑旁的复制、打开（经 `OpenFile`）能用；
  - 提及后草稿里出现提及芯片，焦点在输入框；
  - 删除文件并刷新后，“打开”不再生效，复制路径仍可用。

## 没有验证

- 树行的右键菜单在工作区丢失时，显示、打开、提及三项置灰，但不会检查单个文件是否已删除（树本身在刷新后就不再列出它）。
- Windows 上“在资源管理器中显示”具体打开到哪里，取决于应用层 `ShowInFinder` 的实现，没有在真机上看过。
- Git 页对重命名的改动，复制的是新路径。

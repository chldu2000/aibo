# 03: 详情面板可以拖动宽度

Status: ready-for-agent

**What to build:** 宽窗口里并排显示的详情面板能拖动左边缘改变宽度，宽度在重启后保持。

现状：并排时宽度写死为 `min(400, width*0.42)`（`internal/shell/view.go:103`），面板绝对定位在会话区右侧，没有可拖的边缘。400 看差异太窄，看概览又偏宽。

- [ ] 面板左边缘做成可拖的把手（光标变成左右箭头），拖动改变 `rail`
- [ ] 下限 300，上限为会话区宽度减去消息列的最小可读宽度（建议 360）
- [ ] 宽度只存一档，所有标签页共用（`Pref`）
- [ ] 双击把手回到默认值（400）
- [ ] 窄窗口（叠在消息上的模式，`width < 720`）不受影响
- [ ] Tester：拖动后宽度变化，重建 Shell 后保持

## 决定

- 只存一档（2026-11-27）。用起来发现看差异时总要来回拖，再改成按页分档。

## 实现时查清

- MyGO 是否有现成的可拖边缘控件，还是用 `Split` 改写会话区布局（把详情面板放进 Split 的第二格）。后者更省事，但要处理窄窗口叠放模式。

# 03: 详情面板可以拖动宽度

Status: needs-triage

**What to build:** 宽窗口里并排显示的详情面板能拖动左边缘改变宽度；看文件和差异时能放得比概览宽。

现状：并排时宽度写死为 `min(400, width*0.42)`（`internal/shell/view.go:103`），面板绝对定位在会话区右侧，没有可拖的边缘。400 看差异太窄，看概览又偏宽。

- [ ] 面板左边缘做成可拖的把手（光标变成左右箭头），拖动改变 `rail`
- [ ] 下限 300，上限为会话区宽度减去消息列的最小可读宽度（建议 360）
- [ ] 宽度按页分两档保存（`Pref`）：信息类（概览、终端、子 Agent）一档，内容类（文件、Git）一档；切页时用对应一档
- [ ] 双击把手回到该档的默认值
- [ ] 窄窗口（叠在消息上的模式，`width < 720`）不受影响
- [ ] Tester：拖动后宽度变化并保存；切到 Git 用另一档

## 待定

- 分两档还是每页一档，或者只有一档：需要用户拍板。也可以先做一档，看用起来是否需要分。
- MyGO 是否有现成的可拖边缘控件，还是要用 `Split` 改写会话区布局（把详情面板放进 Split 的第二格）。后者更省事，但要处理窄窗口叠放模式。

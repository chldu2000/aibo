# 15: 会话行显示时间、状态点和未读

Status: resolved

**What to build:** 侧栏的会话行一眼能看出：多久前活跃、是否在运行、是否有用户还没看过的结果。

现状（`internal/shell/sidebar.go` 的 `sessionRow`、`marks`）：一行只有 Agent 图标、标题和状态文字（“运行中”“N 个待审批”“失败”），文字状态占宽；后台会话跑完后，侧栏看不出它有新回复。

- [x] 右侧显示相对时间（`ActiveAt`：刚刚、5 分钟、昨天、11/20），悬停显示完整时间；相对时间文字进 `locales`
- [x] 运行中改为小转圈，待审批改为橙色计数点，失败改为红点，悬停说明原因（保留现在的 Tooltip 文字）
- [x] 行的 Tooltip 加上最后一句话
- [x] 未读：会话完成一轮、或出现需要处理的事时，若没有任何窗口正在显示它，标蓝点；任一窗口显示它即为已读
- [x] 工作台记未读，只在内存里；每个窗口（主窗口和独立窗口）向工作台报告自己正在显示的会话
- [x] 工作台测试：后台会话完成一轮后为未读；打开后为已读；独立窗口正在显示时完成一轮不为未读
- [x] Tester：后台会话完成后出现蓝点，点开后消失

## 决定（2026-11-27）

- 未读不跨重启保留，不加存储迁移。
- 会话行保持一行，不加第二行。
- 任一窗口正在显示就算已读。

## 实现说明

- **工作台（`internal/workbench/unread.go`）**：
  - `Viewing(viewer, id)`：每个窗口报告自己正在显示哪个会话，`id` 为空表示什么都不显示。报告时如果这个会话是未读，就清掉。
  - `attention`：一轮结束（`endTurn`）或收到审批请求时调用。没有任何窗口在显示这个会话时，标为未读。
  - 未读只放在内存里，`Status.Unread` 读出。
  - `LastWords(id)`：最后一条用户消息或 Agent 回复的文字，给会话行的提示用。
- **外壳**：
  - 每个 Shell 用自己的指针地址当 viewer。`View` 发现 `s.current` 变了就报告，`Close` 时报告空。主窗口和独立窗口各是一个 Shell，所以“任一窗口显示就算已读”自然成立。
  - 会话行右侧显示相对时间（`ago`）：刚刚、N 分钟、当天的 N 小时、昨天、月/日，不是今年的再带上年份。悬停显示完整时间。每行请求一分钟后重画一次，让时间往前走。
  - 状态标记：
    - 待审批：橙色圆角计数，标签和提示是“待审批 N”；
    - 运行中：小转圈，标签“运行中”；
    - 失败：红点，提示保留原来的失败原因；
    - 未读：蓝点，标签“有新消息”。
    - 同时满足时按这个顺序只显示一个。
  - 行的提示：最后一句话，压成一行、最多 160 字。只在指针停在这一行上时读取，避免给每个会话都加载消息。
- **测试**：
  - 工作台 `TestUnread`：后台会话完成一轮后未读；主窗口显示它后已读；独立窗口正在显示时完成一轮不算未读；窗口关掉后再完成一轮又是未读；`LastWords` 正确。
  - Tester `TestSessionRowUnread`：后台会话完成后出现蓝点和“刚刚”，点开后蓝点消失。
  - `TestAgo`：各档相对时间。
  - 原有测试按“待审批 1”“运行中”查找的地方，靠标签照旧能找到，不用改。

## 没有验证

- 窗口最小化或被别的窗口挡住时，仍然算“正在显示”，也就是已读。只看 `s.current`，没有接窗口的可见状态。
- 审批请求让会话变成未读的这条路径，没有单独写测试。
- 转圈、计数点、蓝点在侧栏里的尺寸和对齐，没有在真机上看过。

# 15: 会话行显示时间、状态点和未读

Status: ready-for-agent

**What to build:** 侧栏的会话行一眼能看出：多久前活跃、是否在运行、是否有用户还没看过的结果。

现状（`internal/shell/sidebar.go` 的 `sessionRow`、`marks`）：一行只有 Agent 图标、标题和状态文字（“运行中”“N 个待审批”“失败”），文字状态占宽；后台会话跑完后，侧栏看不出它有新回复。

- [ ] 右侧显示相对时间（`ActiveAt`：刚刚、5 分钟、昨天、11/20），悬停显示完整时间；相对时间文字进 `locales`
- [ ] 运行中改为小转圈，待审批改为橙色计数点，失败改为红点，悬停说明原因（保留现在的 Tooltip 文字）
- [ ] 行的 Tooltip 加上最后一句话
- [ ] 未读：会话完成一轮、或出现需要处理的事时，若没有任何窗口正在显示它，标蓝点；任一窗口显示它即为已读
- [ ] 工作台记未读，只在内存里；每个窗口（主窗口和独立窗口）向工作台报告自己正在显示的会话
- [ ] 工作台测试：后台会话完成一轮后为未读；打开后为已读；独立窗口正在显示时完成一轮不为未读
- [ ] Tester：后台会话完成后出现蓝点，点开后消失

## 决定（2026-11-27）

- 未读不跨重启保留，不加存储迁移。
- 会话行保持一行，不加第二行。
- 任一窗口正在显示就算已读。

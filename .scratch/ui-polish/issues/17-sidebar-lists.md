# 17: 工作区分组可折叠，长列表收起

Status: ready-for-agent
Blocked by: 15

**What to build:** 会话多的时候侧栏仍然好找：工作区分组能折叠，每组默认只显示最近几个会话。

现状（`internal/shell/sidebar.go` 的 `workspaceGroups`）：每个工作区下列出全部未归档会话，没有上限；只有“已归档”能折叠。

- [ ] 工作区标题可点击折叠/展开（前面加箭头），状态按工作区用 `Pref` 保存
- [ ] 每组默认显示最近 8 个，下面一行“显示更多（N）”，点开显示全部，再提供“收起”
- [ ] 当前会话、运行中、待审批、未读（15）的会话总是显示，即使排在 8 个之后（未读依赖 15）
- [ ] 折叠的工作区里有运行中或待审批的会话时，标题上显示计数
- [ ] Tester：12 个会话的工作区只显示 8 个加“显示更多”；折叠后重建 Shell 保持折叠

## 待定

# 08: 连续的工具调用合成一组

Status: needs-triage
Type: prototype

**What to build:** Agent 一轮里连续的工具调用合成一行摘要（例如“读了 5 个文件，搜索 2 次，运行 1 条命令”），点开再看每一条；正在运行、等待审批或失败的调用始终单独露出。

现状：每个工具调用是 `messages` 列表里的一行 `Collapsible`（`internal/shell/render.go` 的 `tool`），一轮跑十几个 Read/Grep 时会话里就是十几行，回复正文被挤散。

- [ ] 先做原型（`prototype` 技能），回答：
  - 分组的边界：两段正文之间的所有调用？还是只合并同类调用？
  - 摘要怎么措辞：按 `workbench.ActivityOf` 的类别计数，还是按工具名
  - 运行中的组：展开显示进度，还是只露出最后一个调用
  - 带审批、失败、被中断的调用在组里怎样露出
  - 选择消息（引用）时，组怎样选中：整组还是逐条
- [ ] 原型定稿后补实现清单

## 依据

- `ui.List` 按消息逐行渲染，`seq` 是引用和高亮的单位（`reveal`、`v.highlight`）。分组只改显示，不改消息和 `seq`；高亮落在组内时组要自动展开。

# 08: 连续的工具调用合成一组

Status: needs-triage
Type: prototype

**What to build:** Agent 一轮里连续的工具调用合成一行摘要（例如“读了 5 个文件，搜索 2 次，运行 1 条命令”），点开再看每一条；正在运行、等待审批、失败或被中断的调用始终单独露出。

现状：每个工具调用是 `messages` 列表里的一行 `Collapsible`（`internal/shell/render.go` 的 `tool`），一轮跑十几个 Read/Grep 时会话里就是十几行，回复正文被挤散。

- [ ] 先做原型（`prototype` 技能），按下面的决定看措辞和视觉效果
- [ ] 原型定稿后补实现清单，状态改为 ready-for-agent

## 决定（2026-11-27）

- 分组边界：两段正文之间的所有工具调用合成一组，不分类型。
- 摘要按 `workbench.ActivityOf` 的类别计数。
- 运行中、等待审批、失败、被中断的调用不进组，单独显示在组后。
- 选择模式下所有组自动展开，按条选；引用的单位仍是 `seq`。
- 高亮（`reveal`、`v.highlight`）落在组内时组自动展开。分组只改显示，不改消息和 `seq`。

## 原型后再定

- 摘要的具体措辞和样式；运行中的组怎样表现进度。

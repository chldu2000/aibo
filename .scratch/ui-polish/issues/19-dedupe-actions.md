# 19: 概览只放信息，去掉重复的入口

Status: resolved

**What to build:** 同一个操作只有一个主入口，输入区上方不再常驻次要按钮；概览页只放会话的信息。

现状：
- 标题栏的“选择消息”（`internal/shell/view.go:135`）和徽章行的“引用会话”（`internal/shell/badges.go:84`）都调用 `startSelecting`。
- “压缩”同时在徽章行和概览的“操作”里。
- 概览的“操作”（压缩、重命名、归档、删除）和侧栏的右键菜单重复。
- 徽章行右侧两个按钮总在，加重输入区上方的拥挤（见 13）。

- [x] 标题栏右侧只留三个按钮：引用（进入选择模式）、“…”、详情
- [x] “…”菜单：压缩、重命名、归档或取消归档、在独立窗口打开、删除；和侧栏会话行的右键菜单用同一份定义（侧栏菜单没有的项按条件显示）
- [x] 去掉标题栏单独的“在独立窗口打开”按钮
- [x] 去掉徽章行右侧的“压缩”和“引用会话”；徽章行只显示状态（终端、子 Agent、审批、引用数）
- [x] 概览去掉“操作”一节
- [x] 更新受影响的 Tester 测试

## 决定（2026-11-27）

- 标题栏保留看得见的引用入口；徽章行的去掉。
- “在独立窗口打开”进“…”菜单。

## 实现说明

- **标题栏**：右侧现在只有三个按钮：引用（“选择消息以引用或复制”，进入或退出选择模式）、“…”（“会话的更多操作”）、详情。单独的“在新窗口打开”按钮去掉了。
- **共用菜单**：`sessionMenu`（`internal/shell/sidebar.go`）是标题栏“…”和侧栏会话行右键菜单共用的一份定义，依次是：
  - 压缩上下文：Agent 不支持时不显示，运行中置灰；
  - 重命名…
  - 归档 / 取消归档
  - 在新窗口打开：应用不支持独立窗口时不显示；
  - 分隔线
  - 删除…
- 侧栏菜单因此多了“压缩上下文”和“在新窗口打开”两项。
- **徽章行**：只显示状态（终端、子 Agent、审批、引用数），去掉了右侧的“压缩上下文”和“引用会话…”两个按钮，也删掉了对应的 `tintAction`。
- **概览**：去掉“操作”一节，删除了 `detailsActions` 和 `actionRow`。
- **文案**：删掉不再使用的 `referenceSession`、`referenceSessionLabel`、`detailsActions`，新增 `sessionMore`。
- **测试**：
  - 新增 `TestHeaderMenu`：标题栏正好三个按钮；“…”菜单和侧栏右键菜单内容一致；从“…”重命名和删除都能完成。
  - 更新 `TestStatusBadgesAndDetails`：徽章行没有快捷操作；引用走标题栏；“…”菜单的项和顺序；从菜单在新窗口打开；概览没有操作。
  - 更新 `TestSessionWindow` 和 `TestCompactionSlashAndSelfReference`：从菜单操作。
  - 冒烟测试改为检查“会话的更多操作”。

## 没有验证

- “…”按钮是 MyGO 的 `Element.Menu`，在 macOS 和 Windows 上弹出的是系统菜单，位置和外观没有在真机上看过。
- 运行中，菜单里的“压缩上下文”是置灰的。原来徽章行的按钮运行中也能点，点了会报错，这里算是一个行为变化。

# 19: 概览只放信息，去掉重复的入口

Status: ready-for-agent

**What to build:** 同一个操作只有一个主入口，输入区上方不再常驻次要按钮；概览页只放会话的信息。

现状：
- 标题栏的“选择消息”（`internal/shell/view.go:135`）和徽章行的“引用会话”（`internal/shell/badges.go:84`）都调用 `startSelecting`。
- “压缩”同时在徽章行和概览的“操作”里。
- 概览的“操作”（压缩、重命名、归档、删除）和侧栏的右键菜单重复。
- 徽章行右侧两个按钮总在，加重输入区上方的拥挤（见 13）。

- [ ] 标题栏右侧只留三个按钮：引用（进入选择模式）、“…”、详情
- [ ] “…”菜单：压缩、重命名、归档或取消归档、在独立窗口打开、删除；和侧栏会话行的右键菜单用同一份定义（侧栏菜单没有的项按条件显示）
- [ ] 去掉标题栏单独的“在独立窗口打开”按钮
- [ ] 去掉徽章行右侧的“压缩”和“引用会话”；徽章行只显示状态（终端、子 Agent、审批、引用数）
- [ ] 概览去掉“操作”一节
- [ ] 更新受影响的 Tester 测试

## 决定（2026-11-27）

- 标题栏保留看得见的引用入口；徽章行的去掉。
- “在独立窗口打开”进“…”菜单。

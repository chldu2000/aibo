# 04: 消息底部留白跟随输入区

Status: ready-for-agent

**What to build:** 不管输入区上方叠了多少东西，最后一条消息都不会被输入区挡住；输入框有最大高度。

现状：
- 消息列表底部留白固定 170（`internal/shell/view.go:258`）。输入区是绝对定位的一列：横幅、未开始的审批卡、徽章行、草稿上的芯片、多行草稿，加起来常常超过 170，最后几条消息就压在输入区下面。
- 输入框只有 `MinHeight(44)`，没有最大高度（先核实：粘贴长文时会不会一直长高）。

- [ ] 底部留白取输入区上一帧的高度（`composer.Bounds().H`）加 16 左右；高度变化时，若列表在跟随底部（`FollowEnd`），保持贴底
- [ ] 输入框最大高度约为窗口高度的 40%，超出在框内滚动
- [ ] Tester：叠出三个横幅加一张审批卡时，最后一条消息仍完整可见

## 不做

- 横幅本身怎么合并（13）。

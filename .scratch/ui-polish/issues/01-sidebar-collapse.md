# 01: 侧栏可以收起

Status: ready-for-agent

**What to build:** 用户能把左侧栏收起，让会话区占满窗口，再一键展开。

现状：`View` 总是用 `ui.Split` 画侧栏（`internal/shell/view.go:37`），没有按钮也没有快捷键收起它；窗口很窄时侧栏照样占 260。

- [ ] 侧栏顶部加收起按钮（`sidebar.leading`）；收起后，会话区的浮动标题栏最左侧出现展开按钮（Windows 上在标题栏起点，macOS 上让开红绿灯）
- [ ] 快捷键 ⌘\ / Ctrl+\ 切换收起
- [ ] 收起状态用 `Pref` 保存，重启后保持
- [ ] 窗口宽度小于某个值（建议 640）时自动按收起显示，但不改写保存的偏好；窗口变宽后恢复
- [ ] 收起和展开有过渡（参照 `inspectorMotion`）
- [ ] Tester：点按钮和按快捷键都能切换；收起后能从标题栏展开；重启（重建 Shell）后保持

## 不做

- 侧栏宽度（02）。
- 会话的独立窗口（`Options.Only`）本来就没有侧栏，不受影响。

# 界面国际化

界面语言由宿主管理，支持 `zh-CN`（简体中文）、`en`（英语）和 `system`（跟随系统）。
语言偏好属于应用，不属于工作区、会话或皮肤。切换语言只更新展示数据，不重建会话，
不修改用户消息、Agent 回答、代码、路径、命令名、状态值或能力 ID。

## 语言解析与保存

设置入口为工作台设置 → 外观 → 界面语言。显式选择优先于系统语言；跟随系统时按
`navigator.languages` 的顺序匹配，`zh-*` 使用简体中文，`en-*` 使用英语，均不匹配时使用英语。
繁体中文尚无独立词条，系统的繁体中文偏好目前使用简体中文。

偏好以纯字符串保存在 WebView 的 `aibo.language.v1` localStorage 键中，浏览器预览使用
同一规则。启动读取，切换立即保存，同源窗口通过 storage 事件同步；`languagechange`
事件重新计算跟随系统的语言。存储不可用时当前窗口仍可切换，但不能保证重载后的保存。
实际语言同步到 `<html lang>`。不同 WebView 数据存储分区之间尚不保证同步。

## 分层与词条

- `packages/i18n/`：框架无关的词条、查找、整句参数插值、复数选择和 Intl 格式化。
- `src/lib/app/language-controller.ts`：注入存储和语言来源，管理偏好及变更发布。
- `src/lib/i18n/runtime.ts`：语言和翻译函数的 Svelte store，由 App 初始化。
- 业务投影显式接收 locale；界面通过 `$t` 和 `$locale` 订阅变化。
- 内置主题的显示名称通过 UI kit 展示投影翻译，原始 ID、tokens 和已保存外观保持不变。

词条采用语义 key，保存在 `locales/en.json` 和 `locales/zh-CN.json`。使用完整句子及具名参数，
不按翻译后的文本执行动作。数量词条可使用 `one` / `other` 等复数形式，必须包含 `other`，
并传入有限数值 `count`。字符串插值返回普通文本，不提供 HTML 注入入口。

组件使用 `$t('sidebar.createInWorkspace', { name })`；业务投影使用
`translate(locale, 'commands.new')`。日期和数字显式传入 locale，避免依赖系统默认语言。
新词条须同时补齐两种语言；词条 key 由 TypeScript 校验，参数与复数形式通过 Node 测试检查。

需要在状态中保留的宿主消息使用 `localizedMessage(key, params)`，在展示时由
`translateMessage(locale, value)` 解析。描述符及其参数副本不可变；这样运行中的活动提示和
通知可以随语言切换更新。传入的普通字符串保持原文，用于用户、Agent 或插件提供的内容。
上下文压缩是否进行中由会话状态和事件决定，不能从翻译后的活动文本推断。
宿主校验错误使用 `LocalizedError`，通过 `toErrorText` 保留描述符；`toErrorMessage` 仅供
仍需字符串的消费者显式格式化。整句参数可嵌套宿主消息，路径等列表通过 `localizedList`
在展示时使用 `Intl.ListFormat`，不会翻译列表中的原始字符串。

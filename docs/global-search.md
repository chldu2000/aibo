# 全局搜索

全局搜索由固定宿主面板提供，覆盖所有已添加工作区。双击 Shift 或 Ctrl/⌘ K 打开，标题栏提供鼠标入口。侧栏不再显示搜索按钮或搜索框；会话状态筛选保留。独立命令面板已移除，原有动作归入命令结果。

在搜索输入框或类型按钮上按 Tab，按显示顺序循环切换类型（含「全部」）；Shift+Tab 反向切换。切换后焦点回到输入框，保留关键词和工作区范围，重置结果选择；`>`、`@` 前缀按当前生效类型继续轮换，并移除前缀。输入法组合输入期间不触发切换。范围选择器、详情操作等其他控件保留普通 Tab 焦点导航。

## 搜索内容与操作

| 类别 | 数据来源 | 打开行为 |
| --- | --- | --- |
| 工作区 | 宿主目录、名称和路径 | 激活并展开工作区 |
| 会话 | 所有工作区的宿主持久化会话，包含归档 | 打开活动会话；归档会话进入只读历史 |
| 消息 | 主会话消息、工具输出、子 Agent 最新持久化消息 | 高亮预览；主会话消息可以定位到历史中的命中消息 |
| 文件 | 工作区文件名、相对路径、UTF-8 正文 | 读取当前文件并高亮命中内容 |
| 命令 | 原命令目录、协商后的当前会话命令与 Skills、已安装插件视图 | 应用操作走原执行路径；会话命令填入输入框并保留草稿 |
| 设置、插件 | 设置分类与说明、安装记录 | 打开对应设置分类 |
| 附件、产物 | 持久化元数据及可读取文本 | 校验所属关系后预览；可打开所属会话历史 |
| 执行记录 | 工程任务、工作区写操作、当前窗口的插件调用及事件 | 查看持久化详情 |

搜索不启动 Agent、不取消归档、不改变侧栏筛选，也不重绑会话提供者。是否支持、当前是否可用和最终执行授权仍然独立。命令激活时重新读取当前目录；需确认的操作沿用原确认流程。

默认按类别显示最佳结果，每类最多五条；类别筛选与“查看全部”展示完整分页结果。“加载更多”每次增加 50 条，每类最多 500 条；达到上限时应缩小范围。`>` 前缀只搜命令，`@` 只搜会话。名称精确、前缀、子串匹配依次优先，轻量目录支持子序列匹配；相近结果对当前工作区和最近访问略作加权。历史持久化搜索为文字匹配，不含语义向量或拼音检索。

## 所有权与实现

- `src/lib/app/global-search.ts` 管理查询、来源合并、代际隔离、排序及关闭取消；不依赖 Svelte 或具体 IPC。
- `GlobalSearchPanel.svelte` 展示宿主状态并发出意图。视觉规则位于 UI kit；原生 dialog 负责模态与焦点循环。固定宿主面板在外部皮肤故障时仍可使用。
- `src-tauri/src/global_search.rs` 检索数据库投影，窗口身份由 Tauri 注入，插件调用记录继承现有审计窗口隔离。
- `search_files.rs` 和 `search_assets.rs` 维护文件及附件文本投影。文件读取校验规范化工作区路径，不跟随扫描中的符号链接；详情再次读取并校验所属对象。
- `0051_global_search.sql` 建立可重建的搜索投影与 FTS5 trigram 索引；持久化记录的新增、修改、删除通过事务内触发器同步。子 Agent 消息按会话、Agent 和条目身份折叠到最新快照。
- 外部皮肤隔离文档中的可信键盘桥只发送“打开全局搜索”意图，宿主验证当前呈现仍有效且可交互。旧导航协议的搜索字段保留为空值；旧搜索动作转到全局搜索，随项目发布的导航实现删除旧入口。

## 索引与资源限制

数据库升级时回填宿主持久化数据。三字及以上查询使用 trigram，短词在同一投影上做转义后的子串匹配，中文连续文本与 `%`、`_` 均按文字检索。

数据库启动兼容开发期间已经应用的初版 51 号迁移：`database_migrations.rs` 仅按完整校验值识别 `migration-history/0051_global_search_initial.sql`，用原始 SQL 接受该版本，再执行 `0052_complete_global_search.sql` 补齐文件缓存、审计事件和子 Agent 身份投影。已应用最终版 51 的数据库也通过 52 升级；新库走最终版 51 → 52。既有迁移记录和业务数据保持不变，未知校验值仍被拒绝。两份 51 和已发布迁移必须保持不变，后续结构调整新增迁移。

文件索引按查询后台增量刷新，未变更文件不重复读取；使用 ignore 规则处理 `.gitignore`、`.ignore` 等，并排除 `.git`、`.aibo`、依赖和构建目录。单文件正文限 2 MiB，二进制、非 UTF-8 和超大文件仍可按路径查找。每次工作区扫描最多 50,000 个文件、15 秒及 64 MiB 新文本，命中限制时提示范围不完整；文件详情也有 2 MiB 预览上限。

附件正文按元数据变化刷新，读取已保存的内联内容或工作区文件；产物从宿主内容寻址存储读取。支持 text/*、JSON、XML、JavaScript 和 YAML，不做图片 OCR、PDF/Office 文本提取。文件缺失、内容哈希变化或不可读取时显示原因；不会把这些情况报告成完整无结果。

来源独立加载和失败，关闭或修改查询使旧响应失效。文件取消绑定窗口及请求 ID，不得取消后来的其他查询。索引不访问任意未添加目录或插件私有存储；新数据域通过搜索来源扩展，插件私有数据需要另行定义能力合同后接入。

浏览器探针使用真实 App、ak-ui 浅/深主题与独立打包的 shadcn/Material 3 呈现包，替身仅位于原生 IPC。检查双 Shift、Ctrl/⌘ K、输入焦点、分类/范围、异步旧结果、消息定位、命令执行、窄窗口与焦点恢复。原生测试覆盖中文及符号、更新删除、忽略规则、工作区越界、附件所有权、历史定位和不启动提供者。Tauri 探针验证真实 WKWebView、索引、IPC 与文件预览，双 Shift 使用合成键盘事件；浏览器使用可信键盘事件。两者都不代替各 OS 的物理键盘与输入法组合验证。

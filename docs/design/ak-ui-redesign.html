相对当前实现的改动

悬停条目会在界面上标出对应区域。

  1. 主操作只保留一个几何动作黄色仅用于主操作；切角改用 clip-path，不再用伪元素三角叠底色。
  2. 单行会话，44px 命中区插件图标、标题和相对时间（“19 小时前”）放在一行；状态用图标动画加文字表达，不只靠颜色。
  3. 工作区名不再被截断只为“更多”预留 44px；“在此新建会话”移入菜单。
  4. 会话头部压到 64px视图标签并入头部，只保留一个状态。去掉等宽加宽字距的面包屑，标题使用命令字体。
  5. 消息去噪删除 USER/AGENT 大写标签和每条“完成”，只有异常或运行中才显示状态。正文 14px，行高 1.75。
  6. 工具调用成组折叠一行摘要：多少个调用、多少失败；展开后每条 36px。
  7. Composer 遵循 ak-form 表单样式方角、1px 边框加 4px 左侧信号边；聚焦时信号色边框加 3px 光晕，不使用切角。附件改为 32px 单行 chip，去掉缩放手柄；禁用的发送按钮保留可见边框。
  8. 上下文分区统一对齐去掉标题左竖线；标签和值都左对齐；时间显示相对值，悬停可看完整时间；信任改为成功语义，不再用警告黄。
  9. 执行记录成表状态、命令、耗时、时间放在固定列里。
  10. 标签只有一种选中样式主区、侧栏、Git 子视图都用底部 3px 信号条；列表和导航用左侧条加选中底色。方向键切换时焦点跟随。
  11. Git 单行文件列表状态字母带框和文字标签，文件名在前，目录从左侧截断，右侧显示增删行数，悬停时换成暂存操作；分组计数使用中性色。
  12. 标题栏开关按下状态只用选中底色，不加信号条。
  13. 移动端区域切换使用同一套标签样式；隐藏面包屑和状态栏，内容区大约多出 150px。
  14. 设置去冗余去掉英文眉标和“完成”页脚，主题改为单选卡片，单一皮肤改为一行说明。打开时从顶部开始。

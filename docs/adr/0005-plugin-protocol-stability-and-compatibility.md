# 区分实验协议与稳定协议，执行兼容退出单独决策

2026-09-10 确认：P1 新语义合同标记为实验性，P3 对外发布前冻结首个稳定版本。当前演进期间保留 v1 适配与旧历史读取；内部迁移完成不能自动成为删除旧执行兼容的理由，退出须另行决策。

这一选择让垂直切片阶段能依据验证修正合同，并在外部作者采用前给出明确的稳定边界。过早冻结会锁住未经验证的结构；把所有协议长期视为实验性则让外部插件无法可靠跟随宿主升级。

协议稳定性、执行兼容和历史可读性是不同承诺。稳定版本不能被静默重解释；具体兼容窗口、弃用通知和支持版本策略尚待确定，本决定不承诺永久运行所有旧插件。[ADR-0001](./0001-process-isolated-agent-plugins.md) 中旧 Provider bridge 的阶段限制与 v1 协议适配分别管理；本决定不自动延长旧 bridge 的寿命，也不授权提前删除 v1 adapter。

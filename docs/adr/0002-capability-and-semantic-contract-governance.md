# 能力契约允许命名空间扩展，核心语义视图由宿主治理

2026-09-10 确认：插件可以在自己的命名空间内定义版本化能力契约，并用宿主已有的核心语义视图呈现新业务。核心语义视图种类由宿主治理；新呈现类型必须经过版本化扩展与兼容协商，不能由插件单方面变成所有 renderer 的必需控件。

这一选择允许宿主未知的新业务进入平台，同时控制表现协议的复杂度。要求宿主预先认识每一种业务能力会阻碍生态扩展；允许插件任意定义核心控件则会把语义协议变成新的前端框架，破坏 UI 可替换性。

能力契约声明仍须经过身份、schema、版本和权限验证，不授予任意执行权限。命名空间校验、契约分发与新呈现类型的审批/协商细节待后续设计，不视为已经实现。

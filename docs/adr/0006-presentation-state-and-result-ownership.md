# 宿主持有可恢复的 UI 状态，异步结果按操作语义接纳

2026-09-10 确认：草稿与有意义的浏览位置由宿主持有，按工作区、会话和贡献的适用作用域区分；renderer 只持有悬停、动画等瞬时状态。只读浏览与导航以最新有效意图为准，写入操作独立跟踪执行结果，不因页面离开或选择变化而丢弃。

把可恢复状态仅放在 renderer 中，会使布局或框架切换丢失工作；把所有瞬时状态都交给宿主则增加无必要的同步成本。按操作语义处理结果，既避免旧文件查询覆盖新选择，也避免将已经发生的写入误当作过期页面结果。

草稿跨 renderer 切换、工作区往返和应用重启保留。文件选择、详情与返回位置在切换和工作区往返时保留，应用重启后允许恢复，但必须验证目标仍有效；无效时回到合理入口。焦点保存语义目标，切换时尽量恢复，应用重启不要求还原原焦点。UI 状态不是能力执行的权威数据。

只读旧请求尽量取消，即使取消失败，其迟到结果也不能覆盖当前视图。写入必须保留独立执行状态；离开页面不代表取消成功、执行失败或副作用消失。写入取消、冲突和结果未知的完整流程在 P4 冻结。

具体行为矩阵、验收场景及未定参数见[语义交互与状态规则](../plugin-platform-interaction-decisions.md)。此决定尚待实施，不改变现行 UI 契约。

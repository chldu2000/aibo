# 0002：会话引用是创建时的快照

**Status:** accepted

## Context

会话引用把一个会话（或其中一段）交给另一个会话的 Agent。引用可以是活的链接，始终指向源会话的最新内容；也可以是创建时的快照。

## Decision

引用是快照：创建时固定消息范围和标题。源会话之后新增的内容、改名，都不影响已经发出的引用。Agent 通过工作台的 MCP 工具，按需分页读取快照。

## Consequences

- 结果可以复现：同一个引用，什么时候读都是同样的内容。会话也可以引用给自己，找回被压缩掉的上下文。
- 消息因此只能追加、带序号，不能修改或删除单条。
- 删除源会话会让引用失效。界面里要标出来，删除前要提示有多少引用受影响。

# P4 第三十二批：安装语义视图写动作

本批将安装插件页面的动作接入宿主写入账本，完成真实写入、生命周期及两套皮肤桌面验收。P4 的完整工作台装配与整体退出验收仍未完成。

## 合同与权限边界

保留只读 `aibo.semantic-view/v1` 的解释，新增 semantic view 1.1 合同及 `aibo.semantic-view/v1.1` 快照。声明通过 `writeActions` 将插件命名空间内的动作绑定到能力操作；首批仅支持工作区和会话作用域、页面级动作。

插件只读查询返回动作及其 JSON 输入。界面提交动作标识、宿主上下文和独立请求 ID；宿主从已缓存快照及安装声明解析输入与提供者。界面不能指定实际执行提供者或替换输入。原有只读动作入口拒绝执行写动作。

宿主使用 `semantic.write` 持久记录，复用能力写入的原生审批、工作区占用、取消及结果未知处理。审批前后检查快照、声明包和读写绑定。相同请求的历史结果在查找页面租约前读取，避免页面关闭导致既有执行结果无法重放。

## 页面行为

- 一次动作未结束时，重复点击共享同一请求，不生成第二次写入。
- 写入完成后通过只读刷新获取新快照。
- 写入成功但刷新失败时明确区分这两个结果，保留页面并禁用写动作，等待刷新或重新打开。
- 结果未知时引导检查执行历史和实际结果，不自动重试。
- 页面释放只影响读取与尚未通过的上下文验证；已批准写入由宿主任务持有，界面忽略迟到结果。

## 验收证据

已通过 TypeScript 检查及仓库 `pnpm run verify`；新增控制器测试覆盖重复点击、成功后刷新失败、关闭页面与结果未知。

新增 `fixtures/plugins/semantic-write` 真实 Node 提供者。专项集成测试已验证宿主只读入口拒绝写动作、批准后实际追加文件，以及释放页面、停用提供者和撤销工作区信任后的结果重放不产生第二次写入。另已验证拒绝批准和审批期间释放页面均无文件副作用，Rust 全量 206 项测试通过，随后补充的未声明动作集成测试单独通过。合同正反测试确认 1.0 拒绝新写动作，1.1 拒绝非法输入结构和额外提供者字段。

原生探针 `node probes/semantic-write-native.mjs` 在 macOS 上通过：挂载实际 InstalledWorkbench，分别使用 shadcn 和 material3，点击页面按钮、通过原生批准、抑制重复点击、刷新文本框显示结果，并核对持久账本。外部 runner 核对 `effect.txt` 恰好包含两行写入。证据见 [原生结果](./baselines/plugin-platform-p4/semantic-write-native.json)。

生命周期测试使用真实 Node 子进程：批准并产生副作用后释放页面，延迟响应仍成功落账；执行中重复请求返回 busy；取消慢执行终止后代进程；崩溃及非法输出返回 outcome_unknown。关闭并重新打开数据库后重放四个请求，结果保持一致，文件没有再次写入。此处验证的是数据库与宿主对象重建，不等同于原生应用进程重启探针。

安装合同测试拒绝 1.0 写声明、越权命名空间、重复动作和 application 作用域写入；独立安装修改后的真实提供者验证未声明动作不能打开页面，且无写入副作用。

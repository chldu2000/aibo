# Presentation 插件重构

目标确认于 2026-09-13。决策依据：[ADR-0008](adr/0008-unified-presentation-plugins.md)。

## 产品目标

用户通过一个皮肤插件入口安装、选择、升级、禁用和卸载 Presentation 包。同一包可以只定制主题，也可以提供控件、语义视图和整个工作台；宿主补全未提供的范围。shadcn 与 Material 3 最终作为可独立构建的包验证这条路径，宿主始终保留可用的默认呈现。

成功标准不是移动文件或改名：仓库外构建的包必须能进入实际 App，切换后生效，并且能升级、卸载和从故障中恢复。

## 必须保持的约束

- 会话、草稿、导航、历史与执行结果由宿主持有；呈现卸载不删除业务数据。
- 插件发出语义动作，宿主验证权限、上下文和代际后执行。审批及恢复入口不受可替换代码控制。
- UiKitAdapter 仍是完整内部合同；插件可以省略定制，宿主组合后不能缺少必需控件或核心语义。
- 应用层仅通过 UI kit 使用视觉实现，不按插件或皮肤 ID 分支，不引入视觉 CSS。
- 能力插件无需为换皮肤修改业务协议。新业务数据需求单独进行兼容演进。
- 不把同 WebView 执行或 CSS 作用域宣称为安全隔离。外部可执行包上线前必须确定信任模型及验证证据。

- [ ] 每次交付运行 `pnpm run verify`；涉及原生生命周期时补充对应 Rust 与真实 App 检查。
- [ ] 更新 UI 架构与插件支持矩阵，注明实际平台证据，不将内置模块注册当作外部加载完成。

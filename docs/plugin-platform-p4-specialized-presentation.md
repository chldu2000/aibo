# P4 第三十四批：专业文本阅读与核心回退

原先协商只用于预检，所有结果仍挂载同一个核心适配器。本批将协商结果接入可信适配器注册表，并提供首个真实专业呈现：带行号的 detail 文本阅读。

默认呈现声明 `dev.aibo.ui-default.numbered-detail@1.0.0`。两套皮肤通过现有 UiKit SemanticView 接收语义阅读模式，保持各自视觉实现；安装视图提供通用/带行号阅读切换。collection、settings、inspector 保持核心呈现。

专业和核心适配器接收同一份已校验快照。属性、完整文本、状态、截断提示、读写动作及禁用状态不因回退丢失。动作仍只向宿主传递原上下文与动作标识，专业 UI 不获得执行或批准权限。

缺少适配器或版本不匹配时返回核心视图和诊断。带行号阅读限制为 5,000 行节点；超过限制的首次挂载及后续更新都触发当前皮肤的核心回退，完整文本仍可读取，布局偏好保留。

`pnpm run verify` 通过：25 项架构测试、类型检查、165 项 Node 测试及生产构建。

## 验证范围

- Node 测试验证适配器选择、实现缺失、版本不兼容、必需核心缺失，以及完整快照复制。
- [两套皮肤浏览器证据](./baselines/plugin-platform-p4/specialized-presentation-browser.json)：专业/通用切换、全文与属性、读写动作与禁用状态；版本不兼容、首次挂载失败、更新失败均回退；6,000 行文本不截断。
- [原生安装语义写探针证据](./baselines/plugin-platform-p4/specialized-presentation-native.json)继续验证两套皮肤按钮、宿主审批、重复点击保护、实际文件副作用及刷新显示。

该实例覆盖 detail 专业阅读；collection 选择规则仍由既有核心视图与生命周期验证覆盖。整个 P4 的完整桌面布局、键盘/焦点、无障碍与故障恢复矩阵仍需继续验收，不能由单个专业实例推导全部完成。

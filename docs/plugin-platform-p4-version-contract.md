# P4 第四十批：明确快照版本支持

核心语义版本与快照协议版本分开声明，详见 ADR-0007 的 P4 支持表。旧 renderer 描述符没有 snapshotSchemas 时，仅支持原只读格式；1.1 写动作需显式声明。默认呈现声明 experimental-v1、v1、v1.1，保持当前功能。

描述符校验拒绝未知、重复或缺少稳定 v1 的列表；协商拒绝未支持的快照格式，不通过删除动作来适配旧 renderer。Manifest 激活诊断同步显示语义视图 1.0/1.1，避免与已实现能力矛盾。

验证：

- renderer-negotiation 测试覆盖旧描述符拒绝 1.1、显式支持后完整保留写动作及旧快照兼容。
- Rust manifest 7 项专项测试通过。
- `pnpm run verify` 通过：25 项架构测试、类型检查、167 项 Node 测试及生产构建。
- 两套皮肤专业呈现浏览器探针重跑通过，覆盖 1.1 的完整数据、动作、版本不匹配及挂载/更新失败回退。

本批冻结 P4 版本边界，不宣告完整演进结束；仍需累计退出核对及 P5 SDK/发布验证。

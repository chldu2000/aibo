# @aibo/presentation-workbench

两套独立皮肤共用的纯数据工作台呈现模块。模块只将公开 Presentation 数据和
宿主动作目录转换成视觉树，不引用宿主代码、DOM、框架或业务执行端口。

当前提供 `renderNavigation`、`renderConversation`、`renderGit`、`renderInspector`，
参数均为 `(state, actions)`；`renderCapability(state, actions, renderSemantic)`
接收皮肤自己的语义 renderer。
调用方拥有样式；模块只生成语义结构、可访问性属性及当前目录中的动作绑定。
0.2.0 随双皮肤 0.3.0 交付导航、会话、Git、Inspector 与能力视图的完整工作台。
执行权限、附件状态、诊断、会话绑定、三种布局、草稿以及跨默认呈现的焦点/滚动
恢复均由宿主提供数据与权限；包只决定呈现。macOS arm64 原生生命周期与
Chromium 浏览器交互已有验收记录，未宣称其他 OS 或所有屏幕阅读器通过认证。

`renderWorkbench(input, renderSemantic)` 装配三栏布局的语义结构，外层样式由皮肤
提供。`workbenchSource()` 仅打包本包固定模块，不执行输入源码，不读取宿主源码
或下载第三方依赖。生成的脚本供 Worker 使用。

`./markdown` 导出纯数据解析与目标提取，支持内置呈现既有的 Markdown 子集。
`renderRichText` 只绘制安全视觉树，链接和复制代码按钮必须匹配当前宿主 token。
未提供 token 时按钮禁用，不回退为任意 URL 或包自有剪贴板调用。

工具消息以原文 `pre` 显示调用参数或输出，避免 Markdown 改写命令和 diff；
推理消息使用稳定消息键的原生折叠区域，状态标签保留生成中、失败和中断等区别。
连续工具按组显示数量与完成数；系统消息按宿主 `groupSystemItems` 提示分组，
推理、分支摘要和压缩摘要保持独立。内置呈现与插件共用 `./timeline-model` 的纯数据规则。

编辑器支持 ⌘/Ctrl+Enter：空闲时绑定发送，运行时绑定宿主可用的立即引导；
没有对应动作时不声明快捷键。普通 Enter 仍换行。

可选 `data.layout`/`layoutActions` 让导航及辅助列消费宿主宽度，布局菜单提供
键盘/鼠标范围滑块。缺少合同的旧输入仍使用皮肤默认宽度。尺寸通过受限数值提示
交给皮肤 CSS；分栏边界支持鼠标拖动及方向键/Home/End 调整。

列宽、辅助面板开关及当前视图由宿主按窗口持久化，插件无需自行存储或恢复。

标准、专注和审阅布局消费宿主 mode；审阅交换两侧和拖动方向，专注仅保留内容。
模式菜单使用宿主选择令牌，沿用默认工作台的切换流程和模式持久化。

路径和斜杠命令建议支持上下键、Enter 确认、Escape 收起；路径另支持 Tab。
命令按名称、别名、描述过滤，确认后光标移到补全文本末尾。键盘引用已有宿主
动作；命令分类支持 Tab/Shift+Tab 和鼠标切换。分类是选项列表之外的筛选按钮，
编辑器关联到实际 listbox。会话历史有命名和焦点入口，支持键盘滚动。

路径建议打开时主修饰键 Enter 优先确认选项，与内置编辑器一致；鼠标选择
建议也会回到编辑器，光标位于补全文本末尾。

桌面会话历史与编辑区独立滚动，附件详情可展开；默认视图与外置视图按消息标识
恢复位置。外置核心语义不冒充内置专业阅读，存在专业偏好时显示通用降级提示。
